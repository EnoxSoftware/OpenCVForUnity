Detailed Description

Inspector presets used by SourceToMatControlPanel capability sections (image/video paths, camera device/resolution, source textures, and mat-update FPS).

Presets are optional shortcuts listed after each leading Default: dropdown row. They are not required for a section to appear; inspector defaults are always exposed as Default: entries by SourceToMatControlPanelDefaults even when preset arrays are empty. A preset may reference the same value as the default; both rows remain visible so users can distinguish restoring the scene default from choosing a named shortcut.
