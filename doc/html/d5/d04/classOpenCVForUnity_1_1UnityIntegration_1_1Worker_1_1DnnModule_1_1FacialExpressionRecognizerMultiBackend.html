Detailed Description

Facial expression recognizer with Unity multi-backend inference (OpenCV DNN and Sentis).

This is the primary Unity entry point for facial expression recognition. Inference runs through MultiBackendNet, which supports OpenCV DNN and Unity Sentis backends. For OpenCV-DNN-only usage, use OpenCVForUnity.Extensions.Worker.DnnModule.FacialExpressionRecognizer instead.

Referring to: https://github.com/opencv/opencv_zoo/tree/main/models/facial_expression_recognition

[Tested Models] facial_expression_recognition_mobilefacenet_2022july.onnx https://github.com/opencv/opencv_zoo/blob/main/models/facial_expression_recognition/facial_expression_recognition_mobilefacenet_2022july.onnx

Parameters
modelFilepathPath to the model file. For OpenCV, typically an ONNX file; when MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, a serialized path that Unity.InferenceEngine.ModelLoader.Load(string) can load.
backendPreferred DNN backend: an OpenCV Dnn DNN_BACKEND_* constant, or MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS is selected, Sentis availability is validated by MultiBackendNet.SetPreferableBackend.
targetPreferred DNN target: an OpenCV Dnn DNN_TARGET_* constant, or when backend is MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, a Sentis runtime backend target id (e.g. from SentisInferenceUtils.ToTargetId).
engineOpenCV Dnn ENGINE_* constant used when loading the OpenCV path (default: ENGINE_AUTO). Ignored when backend is MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS. With ENGINE_AUTO, OpenCV tries the new DNN engine first and falls back to classic. The new engine does not support non-CPU backends. Use ENGINE_CLASSIC for CUDA, OpenCL, or other non-CPU backends, and when the new engine produces incorrect results (including on CPU).

Asynchronous variant of RunCoreProcessing for Unity multi-backend inference.

When Sentis is active, runs preprocess / ForwardAsync / postprocess on the async path. On WebGL builds without thread pools, falls back to synchronous RunCoreProcessing on the caller thread. Otherwise delegates to the base background-thread implementation.
