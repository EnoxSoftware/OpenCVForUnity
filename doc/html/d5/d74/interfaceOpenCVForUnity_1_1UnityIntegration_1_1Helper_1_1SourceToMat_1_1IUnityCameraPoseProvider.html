Detailed Description

Unity camera pose matrices for camera OpenCVForUnity.Extensions.SourceToMat.IMatSource implementations.

Facing selection is provided separately by OpenCVForUnity.Extensions.SourceToMat.ICameraFacingControllable. WebCam device enumeration is provided separately by IUnityCameraMatSource.
