Detailed Description

Processing worker that reproduces the face landmarking graph logic of MediaPipe FaceLandmarker on top of the OpenCV for Unity Dnn module.

◆ MediaPipeFaceRunningMode

enum OpenCVForUnity.UnityIntegration.Worker.DnnModule.MediaPipe.MediaPipeFaceLandmarker.MediaPipeFaceRunningMode : byte

Execution modes compatible with the MediaPipe FaceLandmarker task. This enum corresponds to the task running mode that switches between per-image processing and stateful video processing.

Enumerator
IMAGE 

IMAGE mode. Runs face detection and face landmarking for each input image without reusing loopback tracking state from previous frames.

VIDEO 

VIDEO mode. Assumes a frame sequence and reuses face rectangles from the previous frame so the detector can be skipped on frames where tracking remains valid.

Creates a face landmarker worker backed by a face detector model and a face landmark model. This public API maps to the model assets and runtime options used by the MediaPipe face detector graph, face landmarks detector graph, optional FaceBlendshapesGraph, and optional face geometry path.

Parameters
faceDetectorModelFilepathFile path to the face detector model. Corresponds to the detector model asset consumed by the MediaPipe face detector graph.
faceLandmarksModelFilepathFile path to the face landmarks model. Corresponds to the landmark model asset consumed by the MediaPipe SingleFaceLandmarksDetectorGraph path.
runningModeTask running mode. Corresponds to whether the MediaPipe task behaves like single-image processing or stateful video processing with loopback tracking state.
numFacesMaximum number of faces to return. Corresponds to the max number of faces option used by the MediaPipe FaceLandmarker task.
minFaceDetectionConfidenceMinimum confidence for face detections to be kept before later stages. Corresponds to the face detector minimum detection confidence used by the MediaPipe task configuration.
minFacePresenceConfidenceMinimum presence confidence required for landmark results to be treated as present. Corresponds to the face presence threshold used after the landmark model in MediaPipe.
minTrackingConfidenceMinimum tracking confidence required to reuse the previous-frame rectangle. Corresponds to the face tracking confidence gate used by the MediaPipe video pipeline.
outputFaceBlendshapesWhen true, enables the blendshape output; packed rows use the memory layout of FaceBlendshapeEstimationData (second slot when three outputs are returned). Corresponds to the task option that enables FACE_BLENDSHAPES in MediaPipe FaceLandmarker.
faceBlendshapesModelFilepathFile path to the face blendshapes model. Corresponds to the model asset consumed by the MediaPipe FaceBlendshapesGraph path.
outputFacialTransformationMatrixesWhen true, enables the facial transformation matrix output. Corresponds to the task option that enables face geometry output in MediaPipe FaceLandmarker.
faceGeometryPipelineMetadataFilepathFile path to the upstream geometry_pipeline_metadata_landmarks_including_iris.pbtxt file. This corresponds to the geometry pipeline metadata consumed by face geometry calculators.
dnnBackendOpenCV DNN DNN_BACKEND_* constant, or MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS for Unity Inference Engine. When Sentis, use a path loadable by ModelLoader.Load (e.g. .sentis); dnnTarget is cast to BackendType.
dnnTargetOpenCV DNN DNN_TARGET_* constant, or for Sentis an integer cast to Unity Inference Engine BackendType.

◆ Detect()

Mat[] OpenCVForUnity.UnityIntegration.Worker.DnnModule.MediaPipe.MediaPipeFaceLandmarker.Detect ( Mat image,
bool useCopyOutput = false )

High-level inference API equivalent to the synchronous detect entry points of MediaPipe FaceLandmarker. Returns one to three packed output matrices depending on which optional outputs are enabled.

Parameters
imageInput image in BGR 3-channel format. Corresponds to the input image consumed by the MediaPipe face landmarker graph.
useCopyOutputIf true, returns a copied output matrix. If false, returns a view backed by the worker's reusable output buffer.
Returns
Packed result matrices with length 1 or 3. The length is 3 when either outputFaceBlendshapes or outputFacialTransformationMatrixes is enabled, otherwise 1. Element [0] is the packed face result matrix with one row per detected face and FaceLandmarkerEstimationData.ELEMENT_COUNT columns per row. Element [0] is returned as CV_32FC1, and each row matches the memory layout of FaceLandmarkerEstimationData: columns [0 .. 1433] store 478 normalized face landmarks as xyz triplets. When the array length is 3, element [1] contains packed blendshape coefficients or an empty Mat when disabled, with each row returned as CV_32FC1, containing 52 coefficients in category order, and matching the memory layout of FaceBlendshapeEstimationData. Element [2] contains packed row-major 4x4 facial transformation matrices or an empty Mat when disabled, with each row returned as CV_32FC1, containing 16 float values, and matching the memory layout of FacialTransformationMatrixEstimationData.

For the OpenCV Dnn module, inference is scheduled on a background thread when thread-pool scheduling is available.
