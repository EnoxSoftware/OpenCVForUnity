Detailed Description

Factory for Sentis (Unity Inference Engine) inference nets, parallel to OpenCV Dnn.readNet.

Call order: ReadNet → SentisInferenceNet.SetPreferableBackend (no-op) → SentisInferenceNet.SetPreferableTarget → inference. ReadNet loads the Sentis Model immediately when Sentis integration is available; the Sentis Worker is created on SentisInferenceNet.SetPreferableTarget. When integration is unavailable, ReadNet throws NotSupportedException. DNN_BACKEND_UNITY_SENTIS is the canonical Sentis backend discriminator passed to MultiBackendNet.SetPreferableBackend. MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS is a public alias for MultiBackend callers.
