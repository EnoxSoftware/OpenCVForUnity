Detailed Description

Still-image MatSourceBase that implements IImageFileMatSource and IMatUpdateFPSControllable.

ConfigureAwait(false) is used only after MatSourceBase.PlayAsync, MatSourceBase.PauseAsync, and MatSourceBase.StopAsync complete (post-restore playback-state chain). It is not used before grabber open/close on initialization paths.
