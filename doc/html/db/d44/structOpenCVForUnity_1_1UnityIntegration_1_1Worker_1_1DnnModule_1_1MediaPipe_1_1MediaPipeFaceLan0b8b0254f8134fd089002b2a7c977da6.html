Detailed Description

Packed result for one detected facial transformation matrix. The memory layout matches one row of the packed facial transformation matrix result when output_facial_transformation_matrixes is enabled. RowMajor4x4 corresponds to the MediaPipe face geometry output stored as a row-major 4x4 matrix in the same ordering as MatrixData.
