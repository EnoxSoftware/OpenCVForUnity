Detailed Description

Thin wrapper around OpenCV Net that implements IDnnInferenceNet and IDnnInferenceNamedIONet.

Used by Extensions concrete workers such as YOLOXObjectDetector that rely on OpenCV DNN through IDnnInferenceNet. Engines that need alternate inference backends should supply their own IDnnInferenceNet implementation. For models that require named inputs or outputs (e.g. classification or multi-input detection), see optional capability IDnnInferenceNamedIONet.

Typical initialization: OpenCVDnnInferenceDnn.ReadNet(string) or OpenCVDnnInferenceDnn.ReadNet(string, int) / OpenCVDnnInferenceDnn.ReadNet(string, OpenCVDnnInferenceEngineKind) followed by SetPreferableBackend and SetPreferableTarget. Alternatively wrap an existing OpenCV Net with OpenCVDnnInferenceNet(Net).

Output ownership (Forward(System.Collections.Generic.List<Mat>, System.Collections.Generic.List<string>), Forward(string)): the wrapper disposes Mat instances it retained from the previous forward when the next forward runs, and in Dispose. Do not dispose those outputs in application code. Do not pre-fill outputBlobs with foreign Mat and expect the wrapper to own them; only outputs produced by the internal OpenCV Net.forward call are managed.

Output layer names: GetUnconnectedOutLayersNames returns names sorted with DnnInferenceNetUnconnectedOutLayersNames.LAYER_NAME_COMPARER so call sites share one ordering. Pass the same list to Forward(System.Collections.Generic.List<Mat>, System.Collections.Generic.List<string>).
