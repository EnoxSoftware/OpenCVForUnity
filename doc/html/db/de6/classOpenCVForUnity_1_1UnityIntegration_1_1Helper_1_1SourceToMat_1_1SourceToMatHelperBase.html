Detailed Description

Abstract base for Unity MonoBehaviour helpers that expose a wrapped IMatSource. Primary Unity entry is a concrete *ToMatHelper; use MatSource (and capability interfaces) for advanced access; use MultiSourceToMatHelper to switch helper kinds. Does not implement IMatSource; derived helpers own inspector fields and wire a concrete source.

Source naming: Unity object references use Source* (for example SourceTexture); file paths and similar request strings use Requested* (for example RequestedImageFilePath).

Wrapped source contract: MatSource must implement IMatSourceEvents, IMatSourceTickable, IMatSourceReinitializable, and IMatTransformable. For derived frames, also implement IMatSourceDerivedFrames. MatSourceBase is the supported concrete implementation; custom sources should derive from it rather than implementing IMatSource alone.

Inspector UnityEvents are grouped under Lifecycle Events, Frame Events, Error Events, and Derived Frames foldouts. Public properties (OnInitialized, OnFrameMatLayoutChanged, etc.) delegate to those groups.

OnInitialized, OnFrameMatLayoutChanged, OnFrameMatUpdated, OnDerivedFrameLayoutChanged, OnReleased, OnDisposed, and OnErrorOccurred are always invoked on the Unity main thread, even when the wrapped IMatSourceEvents raises its C# events from a background continuation. Property assignments in an OnInitialized listener are copied to MatSource before applied inspector snapshots are recorded: in-place settings apply immediately, and fields that require a new initialize are applied after the in-progress initialize finishes. When the wrapped source raises OnInitialized off the main thread, that flush runs on the next Unity player loop tick with the listener.

Frame consumption patterns (choose one):

PriorityPattern and use case
RecommendedOnFrameMatUpdated — normal frame processing and Inspector wiring. Invoked synchronously after each tick when DidUpdateThisFrame is true.
AlternativeLateUpdate + DidUpdateThisFrame polling — stabilizes execution order when keeping polling. Polling in Update is not recommended because helper ticking and consumer polling order is undefined at the same execution order.
AdvancedAutoTick = false + Tick() or Tick(float) — custom timing such as FixedUpdate or a custom player loop. Set AutoTick to false first; calling public Tick() while AutoTick is true is a no-op (Unity Editor logs a one-time warning). Calling IMatSourceTickable.Tick(float) on MatSource directly bypasses this guard and is for advanced use only.

When coordinating derived frames, cache IDerivedFrame instances from DerivedFrames in an OnInitialized handler. When DerivedFrameSettings.ProcessEveryNFrames is greater than 1, check each derived frame's IDerivedFrame.DidUpdateThisFrame in the OnFrameMatUpdated handler because the primary DidUpdateThisFrame can be true while a derived frame skipped recomputation. Derived DerivedFrameInspectorSettings.ScaleRatio / output color changes are layout-affecting: assigning DerivedFrameSettings syncs immediately when MatSource is set, including while initialization is in progress, and raises OnDerivedFrameLayoutChanged when the derived output layout changes, without waiting for the next source-frame tick and without a full release/re-initialize. Inspector edits still apply after a short delay via OnValidate. DerivedFrameInspectorSettings.ProcessEveryNFrames updates in place and does not raise layout events.

Optional runtime meta properties (for example WebCam autofocus) are available through TryGetMeta(string, out object) and TrySetMeta(string, object). Supported keys depend on the wrapped source; see SourceToMatMetaKeys and SourceToMatUnityMetaKeys.

Gets the event invoked when initialization completes successfully on the Unity main thread.

Assignments in a listener to FlipHorizontal, FlipVertical, Rotate90Degree, OutputColorFormat, InitTimeoutMs, and DerivedFrameSettings are copied to MatSource immediately, including while initialization is still in progress, without waiting for the next Update or the inspector apply delay.
