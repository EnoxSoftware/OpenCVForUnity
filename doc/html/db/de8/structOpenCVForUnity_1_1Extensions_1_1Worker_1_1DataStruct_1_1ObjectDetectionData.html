Detailed Description

Packed object-detection result (axis-aligned bounding box, confidence, and class id) for DNN worker output buffers.

Bounding box corners use image-space (x1, y1, x2, y2) format. Sequential blittable layout; each element occupies DATA_SIZE bytes.
