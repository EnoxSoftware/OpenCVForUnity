Detailed Description

Host message-loop wait loop for SourceToMat grabber Open waits.

Host-loop implementation of the wait loop contract in SourceToMatWait (timeout is InitTimeoutBudget.IsExpired; user CancellationToken is cooperative cancellation only). Do not use InitTimeoutBudget.Token as a timeout signal.

Each tick restores the captured SynchronizationContext with SourceToMatSynchronizationContextScope and then calls SourceToMatHostMarshaling.YieldCapturedSynchronizationContextAsync. Nested scopes are supported, so WaitUntilOnHostLoopAsync may be called from inside an Open SourceToMatSynchronizationContextScope.

Prefer WaitUntilOnHostLoopAsync over a hand-written while around SourceToMatHostMarshaling.YieldCapturedSynchronizationContextAsync.

Event-based waits may use TaskCompletionSource<TResult> and CancellationToken.Register on the user token. Drive the outer wait with WaitUntilOnHostLoopAsync on tcs.Task.IsCompleted. When the budget expires, call TrySetCanceled on the source; do not rely on CancelAfter to unblock the wait.
