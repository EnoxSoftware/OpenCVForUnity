Detailed Description

Controls how often the output IMatSource.FrameMat is updated while playing, for sources that have no native frame rate (for example still images or arbitrary texture readback).

Do not add to MatSourceBase or to camera / video-file sources. Camera sources use ICameraMatSource.RequestedFPS; video sources use IVideoFileMatSource.FPS. Implement on derived mat sources such as ImageFileMatSource that throttle IMatSourceTickable.Tick via FPSThrottle. Integration-layer mat sources that read arbitrary textures without a native frame rate may also implement this interface.
