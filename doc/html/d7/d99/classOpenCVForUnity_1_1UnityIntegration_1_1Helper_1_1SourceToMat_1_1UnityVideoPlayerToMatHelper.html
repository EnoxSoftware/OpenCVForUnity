Detailed Description

Unity helper that reads video files via VideoPlayer and exposes frames through UnityVideoPlayerMatSource implementing IUnityVideoFileMatSource. Primary Unity entry for Unity VideoPlayer files; use SourceToMatHelperBase.MatSource for advanced access; use MultiSourceToMatHelper to switch helper kinds.

Source naming: Unity object references use Source* (for example SourceVideoPlayer); file paths use Requested* (for example RequestedVideoFilePath).

RequestedVideoFilePath accepts a path relative to the StreamingAssets folder or an absolute URI. Before initialization, the helper resolves it through SourceToMatUnityPath.ResolveVideoPlayerPath (not SourceToMatUnityPath.ResolvePath). On WebGL, relative paths become StreamingAssets HTTP(S) URLs suitable for VideoPlayer.url.

Initialization completes in MatSourceState.Ready; call SourceToMatHelperBase.Play or SourceToMatHelperBase.PlayAsync to start delivering frames. SourceToMatHelperBase.OnInitialized is raised once the initialization cycle finishes and the playback state (MatSourceState.Ready, MatSourceState.Playing, or MatSourceState.Paused) is established. During Play mode, inspector changes are applied as follows:

  • SourceVideoPlayer, RequestedVideoFilePath, and RequestedUseAsyncGPUReadback: release and re-initialize the wrapped source. When already MatSourceState.Playing or MatSourceState.Paused, that state is restored before SourceToMatHelperBase.OnInitialized is raised.
  • SourceToMatHelperBase.Rotate90Degree, SourceToMatHelperBase.OutputColorFormat: sync to the wrapped source, which re-establishes the output layout and raises SourceToMatHelperBase.OnFrameMatLayoutChanged.
  • Loop, SourceToMatHelperBase.FlipVertical, SourceToMatHelperBase.FlipHorizontal, SourceToMatHelperBase.InitTimeoutMs: applied in place without re-initialization.
  • SourceToMatHelperBase.DerivedFrameSettings: synchronized by SourceToMatHelperBase; layout-affecting settings fields may raise SourceToMatHelperBase.OnDerivedFrameLayoutChanged.
