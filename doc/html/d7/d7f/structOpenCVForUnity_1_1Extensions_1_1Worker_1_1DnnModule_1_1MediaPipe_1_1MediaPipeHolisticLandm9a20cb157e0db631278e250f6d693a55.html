Detailed Description

Equivalent to upstream MediaPipe HolisticPoseTrackingRequest, which holistic_landmarker_graph.cc passes to TrackHolisticPose.

NeedLandmarks becomes true whenever any of the corresponding outputs is enabled, because pose 2D landmarks are still required internally even for hand-only or face-only requests.
