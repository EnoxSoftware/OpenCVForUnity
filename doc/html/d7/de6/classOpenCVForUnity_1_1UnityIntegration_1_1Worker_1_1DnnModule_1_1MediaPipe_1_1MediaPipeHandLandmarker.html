◆ MediaPipeHandRunningMode

enum OpenCVForUnity.UnityIntegration.Worker.DnnModule.MediaPipe.MediaPipeHandLandmarker.MediaPipeHandRunningMode : byte

Execution modes compatible with the MediaPipe HandLandmarker task. This enum corresponds to the task running mode that switches between per-image processing and stateful video processing.

Enumerator
IMAGE 

IMAGE mode. Runs hand detection and hand landmarking for each input image without reusing loopback tracking state from previous frames.

VIDEO 

VIDEO mode. Assumes a frame sequence and reuses hand rectangles from the previous frame so the detector can be skipped on frames where tracking remains valid.

Creates a hand landmarker worker backed by a palm detector model and a hand landmark model. This public API maps to the model assets and runtime options used by the MediaPipe hand detector graph and hand landmarks detector graph.

Parameters
palmModelFilepathFile path to the palm detector model. Corresponds to the detector model asset consumed by the MediaPipe hand detector graph. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, pass the full path to a serialized model that Unity.InferenceEngine.ModelLoader.Load(string) can load (e.g. .sentis); the caller may rewrite the path from ONNX.
handLandmarksModelFilepathFile path to the hand landmarks model. Corresponds to the landmark model asset consumed by the MediaPipe SingleHandLandmarksDetectorGraph path. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, as for palm, pass the full path to the Inference Engine serialized model.
runningModeTask running mode. Corresponds to whether the MediaPipe task behaves like single-image processing or stateful video processing with loopback tracking state.
numHandsMaximum number of hands to return. Corresponds to the max number of hands option used by the MediaPipe HandLandmarker task.
minHandDetectionConfidenceMinimum confidence for palm detections to be kept before later stages. Corresponds to the hand detector minimum detection confidence used by the MediaPipe task configuration.
minHandPresenceConfidenceMinimum presence confidence required for landmark results to be treated as present. Corresponds to the hand presence threshold used after the landmark model in MediaPipe.
minTrackingConfidenceMinimum tracking confidence required to reuse the previous-frame rectangle. Corresponds to the hand tracking confidence gate used by the MediaPipe video pipeline.
dnnBackendInference backend: an OpenCV Dnn DNN_BACKEND_* constant, or MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, both palm and hand use Unity Inference Engine; dnnTarget is interpreted as an integer Unity.InferenceEngine.BackendType value. Assumes Unity Inference Engine (com.unity.ai.inference) 2.6.1 or newer.
dnnTargetAn OpenCV DNN DNN_TARGET_* constant, or if dnnBackend is MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, an integer to cast to Unity.InferenceEngine.BackendType.

High-level inference API equivalent to the synchronous detect entry points of MediaPipe HandLandmarker. Returns one packed output matrix where each row stores one hand result.

Parameters
imageInput image in BGR 3-channel format. Corresponds to the input image consumed by the MediaPipe hand landmarker graph.
useCopyOutputIf true, returns a copied output matrix. If false, returns a view backed by the worker's reusable output buffer.
Returns
Packed result matrix with one row per detected hand and HandLandmarkerEstimationData.ELEMENT_COUNT columns per row. The matrix is returned as CV_32FC1 and each row matches the memory layout of HandLandmarkerEstimationData. Columns [0 .. 62] store 21 normalized hand landmarks as xyz triplets, columns [63 .. 125] store 21 world hand landmarks as xyz triplets, and column [126] stores the handedness top-1 classification score.

Asynchronous inference API equivalent to the async detect entry points of MediaPipe HandLandmarker. The effective behavior still depends on the configured runningMode.

Parameters
imageInput image in BGR 3-channel format. Corresponds to the input image consumed by the MediaPipe hand landmarker graph.
cancellationTokenCancellation token for the C# async operation.
Returns
Packed result matrix with one row per detected hand and HandLandmarkerEstimationData.ELEMENT_COUNT columns per row. The matrix is returned as CV_32FC1 and each row matches the memory layout of HandLandmarkerEstimationData. Columns [0 .. 62] store 21 normalized hand landmarks as xyz triplets, columns [63 .. 125] store 21 world hand landmarks as xyz triplets, and column [126] stores the handedness top-1 classification score. This method always returns a copied Mat, so the caller owns its lifetime.

For the OpenCV Dnn module, inference is scheduled on a background thread when thread-pool scheduling is available. Web builds cannot use thread pools; only then does the OpenCV Dnn path run synchronously on the caller thread. When OPENCV_SENTIS_AVAILABLE and Sentis is selected, inference uses Sentis forward APIs asynchronously on every platform, including Web.

virtual

Views a packed result matrix as a zero-allocation Span<T> of HandLandmarkerEstimationData.

The returned span remains valid only while result stays allocated and unchanged. If the matrix has more than HandLandmarkerEstimationData.ELEMENT_COUNT columns, interpreting the underlying memory as contiguous rows of HandLandmarkerEstimationData can cross row boundaries. The worker-generated packed matrices use the exact expected column count.

Parameters
resultPacked output matrix: Detect(Mat, bool) at index 0. Each row corresponds to one hand and stores the packed representation of the MediaPipe hand landmarks, hand world landmarks, and handedness outputs.
Returns
Span whose elements correspond to hands in row order. Returns an empty span when the matrix is empty.
