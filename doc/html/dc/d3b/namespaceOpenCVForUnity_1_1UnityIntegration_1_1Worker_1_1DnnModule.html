◆ InferenceFrameworkKind

enum OpenCVForUnity.UnityIntegration.Worker.DnnModule.InferenceFrameworkKind

Discriminator for which inference framework (wrapper family) is active on MultiBackendNet (OpenCV DNN versus Sentis).

Exposed as MultiBackendNet.ActiveInferenceFramework. This is not an OpenCV internal DNN backend id such as DNN_BACKEND_CUDA. MultiBackendNet.PreferredBackend / MultiBackendNet.PreferredTarget remain a separate request axis.

Single-backend nets (OpenCVForUnity.Extensions.Worker.DnnModule.OpenCVDnnInferenceNet, SentisInferenceNet) do not expose this discriminator; their wrapper family is implied by type.

Enumerator

OpenCV DNN path after MultiBackendNet.SetPreferableBackend with an OpenCV DNN_BACKEND_* id (inner OpenCVForUnity.Extensions.Worker.DnnModule.OpenCVDnnInferenceNet).

UnitySentis 

Sentis path after MultiBackendNet.SetPreferableBackend with MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS (or MultiBackendDnn.DNN_BACKEND_UNITY_INFERENCE_ENGINE; same value) (inner SentisInferenceNet).

◆ InferenceFrameworkSelectionKind

enum OpenCVForUnity.UnityIntegration.Worker.DnnModule.InferenceFrameworkSelectionKind

UI selection kind for the inference framework (OpenCV DNN versus Unity Sentis).

Intended for Inspector fields and runtime Dropdowns. Does not include InferenceFrameworkKind.Unknown; an unselected state is not meaningful in UI. Dropdown option order and availability follow InferenceFrameworkUtils.GetSelectionValuesInEnumOrder. Convert to InferenceFrameworkKind with InferenceFrameworkUtils.ToFrameworkKind rather than casting: InferenceFrameworkKind reserves 0 for InferenceFrameworkKind.Unknown.

◆ SentisInferenceTargetKind

enum OpenCVForUnity.UnityIntegration.Worker.DnnModule.SentisInferenceTargetKind

Unity Sentis runtime target kind for MultiBackendNet.SetPreferableTarget.

Underlying values are aligned with Sentis BackendType on supported runtimes (GPU Compute = 0, GPU Pixel = 1, CPU = 2) so Inspector enum indices match Example Dropdowns. Runtime Dropdown option order follows SentisInferenceUtils.GetTargetValuesInEnumOrder (BackendType numeric order). Runtime target ids for MultiBackendNet.SetPreferableTarget are obtained via SentisInferenceUtils.ToTargetId. Callers outside the main OpenCV for Unity assembly can use this enum without referencing Sentis types.
