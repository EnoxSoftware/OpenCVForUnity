Detailed Description

Sentis (Unity Inference Engine) implementation of IDnnInferenceNamedIONet with optional asynchronous forward via IDnnAsyncInferenceNet and IDnnAsyncNamedOutputInferenceNet.

Initialization order: SentisInferenceDnn.ReadNet → SetPreferableBackend (ignored) → SetPreferableTarget (creates the Sentis Worker) → SetInput / Forward. GetUnconnectedOutLayersNames may be called after SentisInferenceDnn.ReadNet, before SetPreferableTarget, because names come from model metadata. Do not call SetInput, Forward, or ForwardAsync before SetPreferableTarget; doing so throws.

Deferred Worker: SentisInferenceDnn.ReadNet loads the Sentis Model immediately when Sentis integration is available. The Sentis Worker is created on the first successful SetPreferableTarget. Input Tensor<float> buffers and output Mat buffers are allocated on the first SetInput and Forward respectively (not during SetPreferableTarget). Dynamic input dimensions from metadata are supported; dynamic rank (isRankDynamic) is not.

Output layer names: GetUnconnectedOutLayersNames returns names sorted with DnnInferenceNetUnconnectedOutLayersNames.LAYER_NAME_COMPARER. Pass the same list to Forward and ForwardAsync as outBlobNames.

SetPreferable*: SetPreferableBackend is a no-op (Sentis has no OpenCV-style backend id). Prefer SetPreferableBackend(SentisInferenceBackendKind) and SetPreferableTarget(SentisInferenceTargetKind) over raw int ids. After the Sentis Worker is created, a later SetPreferableTarget updates the preferred target value but does not recreate the Worker; inference keeps using the BackendType from the first successful initialization. To change the runtime target, Dispose and create a new instance via SentisInferenceDnn.ReadNet.

Output buffers: internal output Mat buffers are reused when output shapes are unchanged; when an input shape changes or the scheduled output shape differs, buffers are reallocated. The same instances are appended each time to the provided list (after List<T>.Clear inside Forward / ForwardAsync). Forward(string) and ForwardAsync(string, CancellationToken) reuse the same internal buffers when the output name matches GetUnconnectedOutLayersNames.

When Sentis integration is unavailable, all instance methods throw NotSupportedException.
