Detailed Description

Subset of OpenCV Net for inference with either OpenCV DNN or Sentis, with deferred initialization after MultiBackendDnn.readNet.

Initialization order (required): MultiBackendDnn.readNet → setPreferableBackend → setPreferableTarget → getUnconnectedOutLayersNames (optional cache) → setInput / forward. Do not call getUnconnectedOutLayersNames, setInput, or forward before both setPreferableBackend and setPreferableTarget; doing so throws.

Deferred loading: the factory does not load OpenCV Net or build a Sentis Worker until the backend and target are set. The Sentis path uses the model’s static input TensorShape from ModelLoader metadata (dynamic input shapes are not supported).

Output layer names: getUnconnectedOutLayersNames returns names sorted with StringComparer.Ordinal so OpenCV DNN and Sentis call sites share one ordering. Pass the same list to forward and forwardTaskAsync as outBlobNames.

Backend id: MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS and the equivalent alias MultiBackendDnn.DNN_BACKEND_UNITY_INFERENCE_ENGINE (same integer discriminator) select the Sentis path only. Neither is OpenCV’s Intel backend id (Dnn.DNN_BACKEND_INFERENCE_ENGINE); those constants differ in value and meaning.

OpenCV mode (forward): the wrapper disposes Mat instances it appended on the previous forward when the next forward runs, and in Dispose. Do not dispose those outputs in application code. Do not pre-fill outputBlobs with foreign Mat and expect the wrapper to own them; only outputs produced by the internal OpenCV Net.forward call are managed.

Sentis mode: internal output Mat buffers are reused; the same instances are appended each time to the provided list (after List<T>.Clear inside forward / forwardTaskAsync).

void OpenCVForUnity.UnityIntegration.Worker.DnnModule.MultiBackendNet.setPreferableBackend ( int backendId)

Commits the DNN backend; triggers lazy creation of the OpenCV Net (non-Sentis) or prepares the Sentis path.

Must be called before setPreferableTarget, getUnconnectedOutLayersNames, and inference. You cannot switch between OpenCV DNN and Sentis on the same instance after the first call.

Parameters
backendIdOpenCV DNN_BACKEND_*, MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, or the equivalent alias MultiBackendDnn.DNN_BACKEND_UNITY_INFERENCE_ENGINE (same value as MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS). Sentis is not OpenCV/Intel Dnn.DNN_BACKEND_INFERENCE_ENGINE (different id).
