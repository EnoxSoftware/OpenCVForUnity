Detailed Description

Closed facade over OpenCV DNN or Sentis inference nets, with deferred initialization after MultiBackendDnn.ReadNet. Implements IDnnInferenceNamedIONet and, as a type, IDnnAsyncInferenceNet / IDnnAsyncNamedOutputInferenceNet (async methods throw on the OpenCV path).

Initialization order (required): MultiBackendDnn.ReadNet → SetPreferableBackend → SetPreferableTarget → GetUnconnectedOutLayersNames (optional cache) → SetInput / Forward. Do not call GetUnconnectedOutLayersNames, SetInput, or Forward before both SetPreferableBackend and SetPreferableTarget; doing so throws.

Deferred loading: the factory does not create the inner net until SetPreferableBackend. OpenCV uses OpenCVDnnInferenceDnn.ReadNet(string, int) with the engine stored from MultiBackendDnn.ReadNet(string, int). Sentis uses SentisInferenceDnn.ReadNet(string) when Sentis integration is available. The engine is ignored on the Sentis path. Inner IDnnInferenceNet.SetPreferableTarget finishes Sentis Worker allocation; see SentisInferenceNet remarks for buffer timing and dynamic shapes.

Output layer names: GetUnconnectedOutLayersNames returns names sorted with DnnInferenceNetUnconnectedOutLayersNames.LAYER_NAME_COMPARER so OpenCV DNN and Sentis call sites share one ordering. Pass the same list to Forward and ForwardAsync as outBlobNames.

Backend id: MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS and the equivalent alias MultiBackendDnn.DNN_BACKEND_UNITY_INFERENCE_ENGINE (same integer discriminator) select the Sentis path only. Neither is OpenCV’s Intel backend id (Dnn.DNN_BACKEND_INFERENCE_ENGINE); those constants differ in value and meaning.

SetPreferable* (re-invocation): SetPreferableBackend and SetPreferableTarget are intended for one-time setup immediately after MultiBackendDnn.ReadNet (as used by *MultiBackend workers and sample scenes).

  • OpenCV path: either method may be called again; each call forwards to the underlying OpenCV Net.
  • Sentis path: switching between OpenCV DNN and Sentis on the same instance after the first SetPreferableBackend throws.
  • Sentis path (target): after the Sentis Worker is created, a later SetPreferableTarget updates PreferredTarget but does not recreate the Worker; inference keeps using the BackendType from the first successful initialization.
  • To change backend or Sentis runtime target, Dispose this instance and create a new one via MultiBackendDnn.ReadNet.

PreferredBackend and PreferredTarget return the last values passed to SetPreferable*; on Sentis they do not reflect a live runtime change after the Worker has been allocated. ActiveInferenceFramework reports which wrapper family was selected at SetPreferableBackend (InferenceFrameworkKind.Unknown before that call).

Provider / target consistency: after SetPreferableBackend, SetPreferableTarget validates that the target id belongs to the active provider (OpenCV DNN_TARGET_* vs Sentis BackendType runtime ids). Cross-stack ids throw ArgumentOutOfRangeException on the int overload; provider-specific enum overloads also throw InvalidOperationException when the enum stack does not match ActiveInferenceFramework.

OpenCV mode (Forward): output Mat ownership matches OpenCVDnnInferenceNet. The wrapper disposes instances it appended on the previous Forward when the next Forward runs, and in Dispose. Do not dispose those outputs in application code. Do not pre-fill outputBlobs with foreign Mat and expect the wrapper to own them; only outputs produced by the internal OpenCV Net.forward call are managed.

Sentis mode: ownership and buffer reuse match SentisInferenceNet (inner implementation).

◆ SetPreferableTarget() [1/3]

void OpenCVForUnity.UnityIntegration.Worker.DnnModule.MultiBackendNet.SetPreferableTarget ( int targetId)

Commits the DNN target (CPU, GPU, etc.); for Sentis, together with SetPreferableBackend, finishes lazy allocation of the Sentis Worker and I/O buffers.

Requires SetPreferableBackend to have been called first. On the OpenCV path, re-invocation updates the underlying Net. On the Sentis path, after the Worker exists, re-invocation updates PreferredTarget only and does not change the allocated Worker (see class remarks). targetId must belong to the active provider: OpenCV DNN_TARGET_* after an OpenCV backend, or a Sentis BackendType runtime id after a Sentis backend. Cross-stack ids throw ArgumentOutOfRangeException; prefer provider-specific enum overloads to catch stack mismatches at compile time where possible.

Parameters
targetIdOpenCV DNN_TARGET_* or a Sentis BackendType value as int.
Exceptions
ArgumentOutOfRangeExceptionThrown when targetId is not a known target for ActiveInferenceFramework.
