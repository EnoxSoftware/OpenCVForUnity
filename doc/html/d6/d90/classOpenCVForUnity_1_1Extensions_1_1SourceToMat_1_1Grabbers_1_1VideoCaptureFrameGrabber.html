Detailed Description

OpenCV VideoCapture-based IFrameGrabber for video files. Returns a new frame from TryGrab only when the source advances at the video frame rate.

Cross-platform video format: Whether OpenCV VideoCapture can open a file depends on the Videoio backend used on each platform (see ApiPreference). On Windows and macOS, formats such as MP4/H.264 often work when the active backend supports them; playback and seek behavior may vary by environment. On browser/WASM hosts and mobile (Android/iOS), formats other than MJPEG are typically unavailable.

Regardless of backend, the only format verified for playback across all supported build targets is AVI container with MJPEG video (Motion JPEG).

Example conversion: ffmpeg -i input.mp4 -c:v mjpeg -q:v 3 -vtag MJPG -an -f avi output.avi

Loop-off end-of-stream: When Loop is false, reaching the end of the stream sets HasReachedEndWithoutLoop to true, holds the last displayed frame (does not seek to the start), and subsequent TryGrab calls return false until playback is restarted (for example via SeekToStart and ClearEndReached).

void OpenCVForUnity.Extensions.SourceToMat.Grabbers.VideoCaptureFrameGrabber.Dispose ( )

Releases native capture resources.

Browser/WebAssembly player builds do not start a reader thread; this method does not join a background thread. On Editor and other multi-threaded players, close joins the reader thread. That join is compiled out of WebGL player builds. Do not copy that join onto WebGL product teardown; use IAsyncDisposable.DisposeAsync on IMatSource instead.
