Detailed Description

Optional capability: asynchronous forward with a list of named outputs.

Standalone capability; does not inherit IDnnInferenceNet or IDnnAsyncNamedOutputInferenceNet. Implementations that also support synchronous inference implement IDnnInferenceNet separately. Callers detect support with a type check (is).
