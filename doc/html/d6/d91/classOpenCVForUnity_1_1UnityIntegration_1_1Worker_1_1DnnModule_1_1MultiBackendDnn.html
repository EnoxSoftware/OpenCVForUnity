Detailed Description

Subset of OpenCV OpenCVForUnity.DnnModule.Dnn for loading models that may run on either OpenCV DNN or Sentis (com.unity.ai.inference).

Backend id DNN_BACKEND_UNITY_SENTIS / DNN_BACKEND_UNITY_INFERENCE_ENGINE is reserved for Sentis. It is not the same value as OpenCV’s Intel OpenVINO backend constant OpenCVForUnity.DnnModule.Dnn.DNN_BACKEND_INFERENCE_ENGINE (different numeric id and vendor).

Call order must follow classic DNN usage: readNet → MultiBackendNet.setPreferableBackend → MultiBackendNet.setPreferableTarget → MultiBackendNet.getUnconnectedOutLayersNames before inference (MultiBackendNet.setInput / MultiBackendNet.forward). Calling MultiBackendNet.getUnconnectedOutLayersNames before both setPreferable* calls will fail.

readNet only stores the model path; it does not load an OpenCV OpenCVForUnity.DnnModule.Net or construct a Sentis Worker until the backend and target are set on MultiBackendNet (see that type for deferred initialization details).
