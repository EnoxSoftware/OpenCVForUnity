Detailed Description

Optional capability: named input/output for classification and multi-input models.

SetInput(Mat, string) may be called multiple times with the same or different inputName values before Forward(string) or IDnnInferenceNet.Forward(System.Collections.Generic.List<Mat>, System.Collections.Generic.List<string>).

Single named output: Forward(string). Multiple inputs with all outputs: combine SetInput(Mat) / SetInput(Mat, string) with inherited IDnnInferenceNet.Forward(System.Collections.Generic.List<Mat>, System.Collections.Generic.List<string>).
