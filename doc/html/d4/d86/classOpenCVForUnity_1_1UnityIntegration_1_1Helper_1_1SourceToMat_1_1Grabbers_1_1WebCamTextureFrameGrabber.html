Detailed Description

Synchronous WebCamTexture-based IFrameGrabber. Returns a new frame from TryGrab only when WebCamTexture.didUpdateThisFrame is true (or when delivering the first frame captured during OpenAsync). The Open body runs inside SourceToMatSynchronizationContextScope.

◆ TryGetLayoutFrame()

bool OpenCVForUnity.UnityIntegration.Helper.SourceToMat.Grabbers.WebCamTextureFrameGrabber.TryGetLayoutFrame ( out Mat frame)

Attempts to get the grabber-owned frame buffer used for layout re-establishment while playing or paused, without advancing playback.

Parameters
frameWhen this method returns true, the held frame buffer owned by the grabber. Callers must treat this Mat as read-only and must not modify it in place. When this method returns false, frame is undefined.
Returns
true when a held frame is available; otherwise false.

Refreshes the held buffer from the current WebCamTexture on the main thread without waiting for WebCamTexture.didUpdateThisFrame, so layout re-establishment receives raw camera pixels rather than a previously orientation-corrected buffer.

Implements OpenCVForUnity.Extensions.SourceToMat.Grabbers.IFrameGrabberLayoutFrame.
