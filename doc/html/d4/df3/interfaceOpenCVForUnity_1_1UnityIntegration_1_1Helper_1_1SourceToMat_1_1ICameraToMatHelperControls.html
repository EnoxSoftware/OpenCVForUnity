Detailed Description

Helper-facing controls for camera sources (device, resolution, and FPS requests). Custom helpers that wrap a camera mat source should implement this so UI and tools can change requests through the helper public API (not by writing MatSource directly). Facing selection is provided separately by ICameraFacingToMatHelperControls.

Request-oriented control-panel API. Effective device name and frame rate are not exposed here; read them from concrete helpers or from ICameraMatSource via MatSource (ICameraMatSource.DeviceName, ICameraMatSource.FPS).
