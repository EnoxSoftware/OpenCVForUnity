Detailed Description

MediaPipe HolisticLandmarker with Unity multi-backend inference (OpenCV DNN and Sentis).

This is the primary Unity entry point for MediaPipe HolisticLandmarker. Inference runs through MultiBackendNet, which supports OpenCV DNN and Unity Sentis backends. For OpenCV-DNN-only usage, use OpenCVForUnity.Extensions.Worker.DnnModule.MediaPipe.MediaPipeHolisticLandmarker instead.

dnnBackendInference backend: an OpenCV Dnn DNN_BACKEND_* constant, or MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS is selected, Sentis availability is validated by MultiBackendNet.SetPreferableBackend.
dnnTargetPreferred DNN target: an OpenCV Dnn DNN_TARGET_* constant, or when dnnBackend is MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, a Sentis runtime backend target id (e.g. from SentisInferenceUtils.ToTargetId).
engineOpenCV Dnn ENGINE_* constant used when loading the OpenCV path (default: ENGINE_AUTO). Ignored when dnnBackend is MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS. With ENGINE_AUTO, OpenCV tries the new DNN engine first and falls back to classic. The new engine does not support non-CPU backends. Use ENGINE_CLASSIC for CUDA, OpenCL, or other non-CPU backends, and when the new engine produces incorrect results (including on CPU).

Asynchronous variant of RunCoreProcessing for Unity multi-backend inference.

When Sentis is active, delegates to RunAsyncGraphCoreProcessingAsync. Otherwise falls back to the base implementation (background-thread RunCoreProcessing; WebGL runs synchronously on the caller thread).
