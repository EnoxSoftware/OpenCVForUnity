Detailed Description

Unity WebCamTexture-backed MatSourceBase that implements IUnityCameraMatSource, ICameraFacingControllable, and IUnityCameraPoseProvider.

Camera permission handling lives in the WebCam grabber OpenAsync path, not here. Orientation correction is applied through the injected IFrameOrientationCorrector.

◆ GetSupportedResolutions()

IReadOnlyList< CameraResolution > OpenCVForUnity.UnityIntegration.Helper.SourceToMat.WebCamTextureMatSource.GetSupportedResolutions ( string deviceNameOrIndex)

Gets supported resolutions for the specified device name or index string.

Parameters
deviceNameOrIndexA device name or index string.
Returns
Supported resolutions for the device, or an empty list when the device is unknown, unsupported, or the backend does not enumerate capture modes (platform-dependent). Order is platform-defined. For UI lists, use CameraResolutionUtils.NormalizeDistinctSorted.

Reads modes from WebCamDevice.availableResolutions. Unity documents that property as available on iOS and Android only; on desktop and most other platforms it is null, so this method returns an empty list. When enumeration is unavailable, use RequestedWidth, RequestedHeight, and RequestedFPS to request a capture size via WebCamTexture construction.
