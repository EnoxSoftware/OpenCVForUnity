Creates a holistic landmarker worker backed by pose, hand, and face models.

Parameters
poseDetectorModelFilepathFile path to the pose detector model. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, pass a path loadable by Unity.InferenceEngine.ModelLoader.Load (e.g. .sentis).
poseLandmarksModelFilepathFile path to the pose landmark model. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, same as the detector path convention.
handLandmarksModelFilepathFile path to the hand landmark model. null or empty disables hand-related outputs.
handRoiRefinementModelFilepathFile path to the hand ROI refinement model. null or empty disables hand-related outputs.
faceDetectorModelFilepathFile path to the face detector model. null or empty disables face-related outputs.
faceLandmarksModelFilepathFile path to the face landmark model. null or empty disables face-related outputs.
runningModeTask running mode.
outputPoseSegmentationMasksWhether pose segmentation masks are exposed in slot 4.
outputFaceBlendshapesWhether face blendshapes are exposed in slot 5.
faceBlendshapesModelFilepathFile path to the face blendshapes model when blendshapes are enabled.
minFaceDetectionConfidenceMinimum confidence for face detections.
minFaceSuppressionThresholdSuppression threshold for face detection filtering.
minFacePresenceConfidenceMinimum presence confidence for face landmark results.
minHandLandmarksConfidenceMinimum confidence for hand landmark results.
minPoseDetectionConfidenceMinimum confidence for pose detections.
minPoseSuppressionThresholdSuppression threshold for pose detection filtering.
minPosePresenceConfidenceMinimum presence confidence for pose landmark results.
dnnBackendInference backend: an OpenCV Dnn DNN_BACKEND_* constant, or MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS is selected, Sentis availability is validated by MultiBackendNet.SetPreferableBackend.
dnnTargetPreferred DNN target: an OpenCV Dnn DNN_TARGET_* constant, or when dnnBackend is MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, a Sentis runtime backend target id (e.g. from SentisInferenceUtils.ToTargetId).
