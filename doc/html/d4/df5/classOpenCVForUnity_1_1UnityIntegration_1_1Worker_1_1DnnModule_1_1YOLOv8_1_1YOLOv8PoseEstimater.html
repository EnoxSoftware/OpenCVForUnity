Parameters
modelFilepathPath to the ONNX model file. For OpenCV, typically an ONNX file; when MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, a serialized path that Unity.InferenceEngine.ModelLoader.Load(string) can load.
classesFilepathPath to the text file containing class names.
inputSizeInput size for the network (default: 640x640).
confThresholdConfidence threshold for filtering detections.
nmsThresholdNon-maximum suppression threshold.
topKMaximum number of output detections.
backendPreferred DNN backend: an OpenCV Dnn DNN_BACKEND_* constant, or MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS is selected, Sentis availability is validated by MultiBackendNet.SetPreferableBackend.
targetPreferred DNN target: an OpenCV Dnn DNN_TARGET_* constant, or when backend is MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, a Sentis runtime backend target id (e.g. from SentisInferenceUtils.ToTargetId).
