Detailed Description

MediaPipe HandLandmarker using OpenCV DNN via OpenCVDnnInferenceNet.

Concrete entry point for MediaPipeHandLandmarkerBase<TNet> that loads palm detection and hand landmark models through OpenCV Net.

Referring to: https://github.com/google-ai-edge/mediapipe

Parameters
palmModelFilepathFile path to the palm detection model (typically an ONNX file).
handLandmarksModelFilepathFile path to the hand landmark model (typically an ONNX file).
runningModeTask running mode.
numHandsMaximum number of hands to return.
minHandDetectionConfidenceMinimum confidence for palm detections.
minHandPresenceConfidenceMinimum presence confidence for landmark results.
minTrackingConfidenceMinimum tracking confidence to reuse the previous-frame rectangle.
backendOpenCV Dnn DNN_BACKEND_* constant.
targetOpenCV Dnn DNN_TARGET_* constant.
engineOpenCV Dnn ENGINE_* constant used when loading models (default: ENGINE_AUTO). With ENGINE_AUTO, OpenCV tries the new DNN engine first and falls back to classic. The new engine does not support non-CPU backends. Use ENGINE_CLASSIC for CUDA, OpenCL, or other non-CPU backends, and when the new engine produces incorrect results (including on CPU).
