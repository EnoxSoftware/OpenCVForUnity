Detailed Description

Shared YOLOv8 pose-estimation algorithm implementation for any IDnnInferenceNet backend.

Template Parameters
TNetInference engine type.

This implementation also supports YOLOv5u, YOLOv9, YOLOv11, and YOLOv12 pose-estimation models exported for OpenCV DNN with the same input/output tensor shapes as YOLOv8.

Type Constraints
TNet :IDnnInferenceNet

virtual Mat OpenCVForUnity.Extensions.Worker.DnnModule.YOLOv8.YOLOv8PoseEstimaterBase< TNet >.Estimate ( Mat image,
bool useCopyOutput = false )
virtual

Estimates poses in the input image.

This is a specialized method for pose estimation that:

  • Takes a single BGR image as input
  • Returns a Mat containing pose estimation result (57 columns per detection)

The returned Mat format:

  • Each row represents one detected person
  • Columns: [x1, y1, x2, y2, confidence, classId, kpt0_x, kpt0_y, kpt0_conf, ... kpt16_x, kpt16_y, kpt16_conf]
  • Keypoint columns: 51 values (17 keypoints × 3: x, y, confidence)
  • Use ToStructuredData() or ToStructuredDataAsSpan() to convert to a more convenient format

Output options:

  • useCopyOutput = false (default): Returns a reference to internal buffer (faster but unsafe across executions)
  • useCopyOutput = true: Returns a new copy of the result (thread-safe but slightly slower)

For better performance in async scenarios, use EstimateAsync(Mat, CancellationToken).

Parameters
imageInput image in BGR format.
useCopyOutputWhether to return a copy of the output (true) or a reference (false).
Returns
A Mat containing pose estimation result. The caller is responsible for disposing this Mat.

Estimates poses in the input image asynchronously.

This is a specialized async method for pose estimation that:

  • Takes a single BGR image as input
  • Returns a Mat containing pose estimation result (57 columns per detection)

The returned Mat format:

  • Each row represents one detected person
  • Columns: [x1, y1, x2, y2, confidence, classId, kpt0_x, kpt0_y, kpt0_conf, ... kpt16_x, kpt16_y, kpt16_conf]
  • Keypoint columns: 51 values (17 keypoints × 3: x, y, confidence)
  • Use ToStructuredData() or ToStructuredDataAsSpan() to convert to a more convenient format

Only one pose estimation operation can run at a time.

The default implementation schedules synchronous inference on a background thread. Derived types may override asynchronous inference when a backend-specific async API is available.

Parameters
imageInput image in BGR format.
cancellationTokenOptional token to cancel the operation.
Returns
A task that represents the asynchronous operation. The task result contains a Mat with pose estimation result. The caller is responsible for disposing this Mat.
