Detailed Description

Packed result for one detected face. The memory layout matches one row produced by BuildPackedOutputMats. NormLandmarks corresponds to the MediaPipe Task API face_landmarks output represented as 478 Vec3f values. Face-level raw presence scores are not included; the internal threshold is configured by the MediaPipeFaceLandmarker constructor.
