Detailed Description

Initialization and re-initialization with playback state restoration for a IMatSource implementation.

Not part of IMatSource. Implemented by MatSourceBase. Hosts that release and re-initialize to apply source-swap changes (for example a new path or texture) while restoring playback state consume this interface on the concrete source.

End users should call IMatSource.InitializeAsync(System.Threading.CancellationToken) and then IMatSource.PlayAsync(System.Threading.CancellationToken). Mode-aware initialization is intended for those source-swap re-initialization paths by advanced hosts.
