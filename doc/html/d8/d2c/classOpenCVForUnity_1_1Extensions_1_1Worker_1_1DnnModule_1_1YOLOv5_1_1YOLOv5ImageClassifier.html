Detailed Description

YOLOv5 image classifier using OpenCV DNN via OpenCVDnnInferenceNet.

Concrete entry point for YOLOv5ImageClassifierBase<TNet> that loads the classification model through OpenCV Net.

[Tested Models] yolov5n-cls.onnx

Parameters
modelFilepathPath to the model file (typically an ONNX file).

inputSizeInput size for the network (default: 224x224).
backendOpenCV Dnn DNN_BACKEND_* constant.
targetOpenCV Dnn DNN_TARGET_* constant.
engineOpenCV Dnn ENGINE_* constant used when loading the model (default: ENGINE_AUTO). With ENGINE_AUTO, OpenCV tries the new DNN engine first and falls back to classic. The new engine does not support non-CPU backends. Use ENGINE_CLASSIC for CUDA, OpenCL, or other non-CPU backends, and when the new engine produces incorrect results (including on CPU).
