Detailed Description

Helpers for mapping InferenceFrameworkSelectionKind to InferenceFrameworkKind and UI labels.

GetSelectionValuesInEnumOrder is the source of truth for runtime Dropdown options. Callers should resolve a Dropdown index through that array rather than casting the index to InferenceFrameworkSelectionKind.
