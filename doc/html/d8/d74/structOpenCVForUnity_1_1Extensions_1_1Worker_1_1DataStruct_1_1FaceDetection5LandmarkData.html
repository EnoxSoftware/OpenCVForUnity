Detailed Description

Packed face-detection result with a bounding box, five facial landmarks, and a confidence score for DNN worker output buffers.

Sequential blittable layout; each element occupies DATA_SIZE bytes. When stored as a detection result OpenCVForUnity.CoreModule.Mat row (15 columns, CV_32FC1), field order matches OpenCV FaceDetectorYN::detect output: columns 0–3 bbox (x, y, w, h), 4–13 five landmarks (x, y pairs), 14 score.
