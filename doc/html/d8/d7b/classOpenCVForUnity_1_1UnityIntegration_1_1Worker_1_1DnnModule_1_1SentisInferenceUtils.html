Detailed Description

Helpers for mapping SentisInferenceBackendKind and SentisInferenceTargetKind to Sentis runtime ids and UI labels.

Sentis-specific conversion is compiled only when OPENCV_SENTIS_AVAILABLE is set on the main assembly. Public members are always available so Example and user assemblies can branch with OpenCVForUnityEnv.IsSentisIntegrationAvailable without defining OPENCV_SENTIS_AVAILABLE.
