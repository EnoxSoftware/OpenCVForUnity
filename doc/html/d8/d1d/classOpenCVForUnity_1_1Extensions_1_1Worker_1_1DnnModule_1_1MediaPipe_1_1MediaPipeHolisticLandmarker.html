Detailed Description

MediaPipe HolisticLandmarker using OpenCV DNN via OpenCVDnnInferenceNet.

Concrete entry point for MediaPipeHolisticLandmarkerBase<TNet> that loads pose, hand, and face models through OpenCV Net. Pose models are required; hand and face models are optional and enabled when both paths in each pair are non-empty.

Referring to: https://github.com/google-ai-edge/mediapipe
