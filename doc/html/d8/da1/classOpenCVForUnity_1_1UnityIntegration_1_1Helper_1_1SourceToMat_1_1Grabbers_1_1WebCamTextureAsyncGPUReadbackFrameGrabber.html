Detailed Description

AsyncGPUReadback-based WebCamTexture IFrameGrabber. Returns a new frame from TryGrab only when a capture request has completed (or when delivering the first frame captured during OpenAsync). The Open body runs inside SourceToMatSynchronizationContextScope.

WebCam frame pipeline (hot path):

  1. TryBeginCaptureFromWebCamUpdate calls BeginCapture when WebCamTexture.didUpdateThisFrame is true.
  2. OnAsyncReadbackComplete stores the latest completed readback in _asyncGpuReadbackRequest and marks it ready to commit.
  3. TryGrab calls TryCommitPendingCapture at most once per tick to copy the latest completed frame into _frameMat and return it.

Capture dedup: at most one readback is issued per Unity frame while WebCamTexture.didUpdateThisFrame is true. Parallel readbacks across different Unity frames are allowed. _readbackGeneration invalidates in-flight readbacks on pause, stop, and close.

bool OpenCVForUnity.UnityIntegration.Helper.SourceToMat.Grabbers.WebCamTextureAsyncGPUReadbackFrameGrabber.TryGrab ( out Mat frame)

Attempts to grab a newly available frame into a working buffer owned by the grabber.

Parameters
frameWhen this method returns true, the grabbed frame buffer owned by the grabber. Callers such as MatSourceBase treat this Mat as read-only and must not modify it in place. When this method returns false, frame is undefined.
Returns
true when a new frame was grabbed and is ready for the pipeline; false when no new frame is available for this call (normal for video / camera sources between frame updates). Returning false is not an error by itself.

During playback, begins capture when WebCamTexture.didUpdateThisFrame is true, then commits the latest completed readback when available. Returns false when no new frame was delivered this tick (not an error).
