Detailed Description

Shared wait loop for SourceToMat initialization and first-frame waits.

Timeout is InitTimeoutBudget.IsExpired (stopwatch / wall-clock remaining budget). Do not use InitTimeoutBudget.Token as the loop condition, as a CancellationToken.Register timeout, or as the only CancellationToken.ThrowIfCancellationRequested deadline. InitTimeoutBudget.Token is cooperative user cancellation only. On some single-threaded hosts, time-based token cancellation such as CancellationTokenSource.CancelAfter does not fire, so a loop that waits only on that token never ends.

Loop contract:

  • While InitTimeoutBudget.IsExpired is false, throw if the user token is canceled, return true when the predicate is true, otherwise await one tick.
  • Return false when the budget expires before the predicate becomes true (timeout).
  • Throw OperationCanceledException when the user token is canceled.

The caller supplies yieldOneTickAsync: one scheduling step per loop iteration. Host integrations that must pump the main message loop should inject a tick that advances that loop. Callers already on a compatible SynchronizationContext may pass a delegate that awaits Task.Yield. Do not use Task.Delay (including a delay of zero) as the tick.
