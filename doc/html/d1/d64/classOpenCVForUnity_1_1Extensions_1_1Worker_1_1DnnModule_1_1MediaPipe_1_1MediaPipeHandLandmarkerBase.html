◆ Detect()

Mat OpenCVForUnity.Extensions.Worker.DnnModule.MediaPipe.MediaPipeHandLandmarkerBase< TNet >.Detect ( Mat image,
bool useCopyOutput = false )

High-level inference API equivalent to the synchronous detect entry points of MediaPipe HandLandmarker. Returns one packed output matrix where each row stores one hand result.

Parameters
imageInput image in BGR 3-channel format. Corresponds to the input image consumed by the MediaPipe hand landmarker graph.
useCopyOutputIf true, returns a copied output matrix. If false, returns a view backed by the worker's reusable output buffer.
Returns
Packed result matrix with one row per detected hand and HandLandmarkerEstimationData.ELEMENT_COUNT columns per row. The matrix is returned as CV_32FC1 and each row matches the memory layout of HandLandmarkerEstimationData. Columns [0 .. 62] store 21 normalized hand landmarks as xyz triplets, columns [63 .. 125] store 21 world hand landmarks as xyz triplets, and column [126] stores the handedness top-1 classification score.

Asynchronous inference API equivalent to the async detect entry points of MediaPipe HandLandmarker. The effective behavior still depends on the configured runningMode.

Parameters
imageInput image in BGR 3-channel format. Corresponds to the input image consumed by the MediaPipe hand landmarker graph.
cancellationTokenCancellation token for the C# async operation.
Returns
Packed result matrix with one row per detected hand and HandLandmarkerEstimationData.ELEMENT_COUNT columns per row. The matrix is returned as CV_32FC1 and each row matches the memory layout of HandLandmarkerEstimationData. Columns [0 .. 62] store 21 normalized hand landmarks as xyz triplets, columns [63 .. 125] store 21 world hand landmarks as xyz triplets, and column [126] stores the handedness top-1 classification score. This method always returns a copied Mat, so the caller owns its lifetime.

For the OpenCV Dnn module, inference is scheduled on a background thread when thread-pool scheduling is available. Web builds cannot use thread pools; only then does the OpenCV Dnn path run synchronously on the caller thread.

◆ ToStructuredDataAsSpan()

virtual Span< HandLandmarkerEstimationData > OpenCVForUnity.Extensions.Worker.DnnModule.MediaPipe.MediaPipeHandLandmarkerBase< TNet >.ToStructuredDataAsSpan ( Mat result)
virtual

Views a packed result matrix as a zero-allocation Span<T> of HandLandmarkerEstimationData.

The returned span remains valid only while result stays allocated and unchanged. If the matrix has more than HandLandmarkerEstimationData.ELEMENT_COUNT columns, interpreting the underlying memory as contiguous rows of HandLandmarkerEstimationData can cross row boundaries. The worker-generated packed matrices use the exact expected column count.

Parameters
resultPacked output matrix: Detect(Mat, bool) at index 0. Each row corresponds to one hand and stores the packed representation of the MediaPipe hand landmarks, hand world landmarks, and handedness outputs.
Returns
Span whose elements correspond to hands in row order. Returns an empty span when the matrix is empty.
