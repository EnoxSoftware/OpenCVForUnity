Detailed Description

Helper-facing controls for video-file sources. Custom helpers that wrap a video-file mat source should implement this so UI and tools can change requests through the helper public API (not by writing MatSource directly).

Minimal control-panel API: RequestedVideoFilePath, Loop, and FramePosRatio only. Read-only playback state and diagnostics such as FPS, FrameIndex, and FrameCount are on concrete helpers or on IVideoFileMatSource via MatSource.
