Detailed Description

Helper-facing controls for image-file sources. Custom helpers that wrap an image-file mat source should implement this so UI and tools can change requests through the helper public API (not by writing MatSource directly).

Minimal control-panel API for image path and Repeat. Mat-update rate is on IMatUpdateFPSToMatHelperControls (separate contract).
