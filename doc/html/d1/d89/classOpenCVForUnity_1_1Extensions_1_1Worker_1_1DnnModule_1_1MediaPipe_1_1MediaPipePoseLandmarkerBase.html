◆ ResetTrackingState()

virtual void OpenCVForUnity.Extensions.Worker.DnnModule.MediaPipe.MediaPipePoseLandmarkerBase< TNet >.ResetTrackingState ( )
virtual

Clears inter-frame tracking state held between frames.

Resets _prevPoseRectsFromLandmarks (previous-frame pose ROI loopback) and landmark smoothing filters. In IMAGE mode, ProcessImageData already clears pose ROI loopback on every call, so this method is effectively a smoothing reset only; it is still safe to call when the input source, resolution, or layout changes. In VIDEO mode, call this when prior tracking must not influence the next inference.

◆ ToStructuredDataAsSpan()

virtual Span< PoseLandmarkerEstimationData > OpenCVForUnity.Extensions.Worker.DnnModule.MediaPipe.MediaPipePoseLandmarkerBase< TNet >.ToStructuredDataAsSpan ( Mat result)
virtual

Views a packed result matrix as a zero-allocation Span<T> of PoseLandmarkerEstimationData.

The returned span remains valid only while result stays allocated and unchanged. If the matrix has more than PoseLandmarkerEstimationData.ELEMENT_COUNT columns, interpreting the underlying memory as contiguous rows of PoseLandmarkerEstimationData can cross row boundaries. The worker-generated packed matrices use the exact expected column count.

Parameters
resultPacked output matrix returned by Detect(Mat, bool) or a compatible source. Each row corresponds to one pose and stores the packed representation of the MediaPipe pose landmarks and pose world landmarks outputs.
Returns
Span whose elements correspond to poses in row order. Returns an empty span when the matrix is empty.
