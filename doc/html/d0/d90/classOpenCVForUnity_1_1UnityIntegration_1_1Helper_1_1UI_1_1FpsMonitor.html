Detailed Description

FpsMonitor Displays FPS and optional key-value diagnostics in a screen overlay, plus a bottom console bar for status messages. UI is created at runtime from a Canvas prefab and scales with screen resolution via Canvas Scaler.

Layout limits (canvas coordinates):

  • FPS panel width: up to one third of the canvas width
  • FPS panel height: up to the canvas height minus vertical screen margins
  • Console panel height: up to one third of the canvas height

The FPS panel uses a fixed font size (FPS_DEFAULT_FONT_SIZE). Overflowing text can be viewed by dragging vertically (no scrollbar). The console panel reduces font size automatically when possible to fit its content, then enables vertical drag scrolling when text still overflows at the minimum font size. When content fits without scrolling, panel raycasts are disabled so touches pass through to UI behind the overlay.

The FPS panel grows with content but does not shrink until Clear is called or the screen/canvas size changes.
