Detailed Description

Secondary facade that switches the active SourceToMatHelperBase kind on this GameObject. Primary Unity entry remains a concrete *ToMatHelper; use ActiveHelper and its SourceToMatHelperBase.MatSource (and capability interfaces) for advanced access.

Does not implement IMatSource. Prefer the active helper's MatSource for advanced use and capability interfaces (for example ICameraFacingControllable).

Source naming: Unity object references use Source*; file paths and similar request strings use Requested*.

Source-specific inspector fields live on the child helper (and in MultiSourcePerKindSettings caches). Common transform / output / tick settings, shared derived-frame settings, and shared UnityEvents are owned by this component and applied via ApplyCommonSettingsToActiveHelper.

Runtime kind switches use SwitchHelperAsync: pull per-kind cache, release, replace the child helper, push cache, apply common settings, then initialize. Overlapping switch or initialize calls are ignored while a switch is in progress. Child inspector edits are pulled into the matching cache from OnValidate (not every Play-mode frame). Custom uses CustomHelperComponent only and is excluded from per-kind Pull/Push.

On single-threaded hosts (for example browser/WebAssembly targets), product teardown must call DisposeAsync; do not use Dispose.

void OpenCVForUnity.UnityIntegration.Helper.SourceToMat.MultiSourceToMatHelper.ApplyHelperKindInEditMode ( MultiSourceHelperKind kind)

Edit-mode only: pulls per-kind cache, replaces the active child helper for kind , pushes cache, and applies common settings (including shared UnityEvent references).

No-op while playing — use SwitchHelperAsync (or RequestedHelperKind) at runtime so Edit-time DestroyImmediate does not race with a Play-mode switch. When kind is MultiSourceHelperKind.Custom and CustomHelperComponent is unset, built-in helpers are removed and ActiveHelper becomes null without throwing.

void OpenCVForUnity.UnityIntegration.Helper.SourceToMat.MultiSourceToMatHelper.PullPerKindSettingsFromActiveHelper ( )

Copies inspector settings from ActiveHelper into the matching per-kind cache.

Uses the active helper's concrete type to select the cache bucket so WebCam ↔ ImageFile round-trips keep each kind's settings. Custom helpers are skipped (component reference only). Common settings are not copied. VideoCapture ApiPreference is options-only and is not cached. Kind mismatch against RequestedHelperKind logs a warning and still pulls by helper type.
