Detailed Description

Unity helper that loads a still image file via ImageFileFrameGrabber and exposes frames through ImageFileMatSource. Primary Unity entry for image files; use SourceToMatHelperBase.MatSource for advanced access; use MultiSourceToMatHelper to switch helper kinds.

Source naming: file paths use Requested* (here RequestedImageFilePath); Unity object references use Source*.

RequestedImageFilePath is relative to the StreamingAssets folder or an absolute path/URI. Initialization completes in MatSourceState.Ready; call SourceToMatHelperBase.Play or SourceToMatHelperBase.PlayAsync to start delivering frames. SourceToMatHelperBase.OnInitialized is raised once the initialization cycle finishes and the playback state (MatSourceState.Ready, MatSourceState.Playing, or MatSourceState.Paused) is established. During Play mode, inspector changes are applied as follows:

  • RequestedImageFilePath: release and re-initialize the wrapped source. When already MatSourceState.Playing or MatSourceState.Paused, that state is restored before SourceToMatHelperBase.OnInitialized is raised.
  • SourceToMatHelperBase.Rotate90Degree, SourceToMatHelperBase.OutputColorFormat: sync to the wrapped source, which re-establishes the output layout and raises SourceToMatHelperBase.OnFrameMatLayoutChanged.
  • RequestedMatUpdateFPS, Repeat, SourceToMatHelperBase.FlipVertical, SourceToMatHelperBase.FlipHorizontal, SourceToMatHelperBase.InitTimeoutMs: applied in place without re-initialization. Mat-update throttling and repeat delivery are inactive while MatSourceState.Paused.
  • SourceToMatHelperBase.DerivedFrameSettings: synchronized by SourceToMatHelperBase; layout-affecting settings fields may raise SourceToMatHelperBase.OnDerivedFrameLayoutChanged.
