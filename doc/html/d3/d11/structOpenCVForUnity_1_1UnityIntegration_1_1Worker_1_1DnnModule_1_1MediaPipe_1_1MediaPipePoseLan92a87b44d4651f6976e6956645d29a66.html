Detailed Description

Packed result for one pose from Pose Landmarker. Memory-compatible with each row produced by PackResultsToMats. Order: 33 elements corresponding to the original NormalizedLandmark values (x, y, z, visibility, presence) followed by 33 elements corresponding to the original Landmark values with the same five components. The user-facing MediaPipe PoseLandmarker result does not expose a pose-level raw presence score, so this packed representation does not include it either; the threshold is applied inside the graph using the constructor's minPosePresenceConfidence.
