Detailed Description

Packed COCO 17-keypoint pose-estimation result (bounding box, confidence, class id, and landmarks) for DNN worker output buffers.

Mat row layout (57 floats): [x1, y1, x2, y2, confidence, classId, landmark1_x, landmark1_y, landmark1_conf, ...]. Landmarks are stored as 17 OpenCVForUnity.Extensions.Vec3f values flattened into RawLandmarks. Sequential blittable layout; each element occupies DATA_SIZE bytes.
