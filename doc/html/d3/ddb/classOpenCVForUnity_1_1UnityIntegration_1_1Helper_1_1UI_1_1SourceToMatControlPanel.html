Detailed Description

Runtime control panel for SourceToMat helpers. Loads UI from a Canvas prefab under Resources, wires transport, transform, and capability controls through SourceToMatControlTarget, and exposes UnityEvent hooks after helper updates.

Prefab resource name: SourceToMatControlPanelCanvas_OpenCV (path: SourceToMatControlPanel/Resources/). Expected hierarchy (child names):

  • Tab — top tab button that expands or collapses the drawer
  • Drawer — scrollable drawer root (collapsed by default; Viewport/Content inside)
  • Drawer/Viewport/Content/TransportSection/Body — Play / Pause / Stop; Initialize / Release (optional; visibility from Inspector)
  • Drawer/Viewport/Content/TransformSection/Body — Rotate90 / FlipVertical / FlipHorizontal
  • Drawer/Viewport/Content/CapabilitySection/MultiSection/Body — HelperKindDropdown (first when Multi)
  • Drawer/Viewport/Content/CapabilitySection/ImageSection/Body — ImagePathDropdown, RepeatToggle
  • Drawer/Viewport/Content/CapabilitySection/VideoSection/Body — VideoPathDropdown, LoopToggle, FramePosRatioSlider
  • Drawer/Viewport/Content/CapabilitySection/CameraSection/Body — DeviceDropdown (leading Auto sets empty RequestedDeviceName), ResolutionDropdown, FrontFacingToggle
  • Drawer/Viewport/Content/CapabilitySection/TextureSection/Body — SourceTextureDropdown
  • Drawer/Viewport/Content/CapabilitySection/MatUpdateFPSSection/Body — MatUpdateFPSDropdown

Font on UI Text elements must be LegacyRuntime.ttf (not Arial.ttf). Canvas sortingOrder defaults above FpsMonitor and below example documentation so overlays coexist. Capability sections rebuild after helper-kind switches (by requested kind), SourceToMatHelperBase.OnInitialized, and SourceToMatHelperBase.OnErrorOccurred.

Section visibility: Image, video, camera, texture, and mat-update FPS sections follow helper capability (or requested helper kind on multi targets). Texture does not require SourceToMatControlPresets.SourceTexturePresets; a capability-only helper still shows SourceTextureDropdown with a Default: entry when applicable.

Default dropdown entries: Inspector defaults are snapshotted when the panel first binds a target (see SourceToMatControlPanelDefaults) and exposed as permanent leading Default: items (including empty paths and null textures). Presets from Presets are optional shortcuts listed after the default row; a preset may reference the same value as the default and both rows remain visible. Camera device defaults that are empty (auto selection) do not add a separate Default: row because the leading Auto option already represents that request. Snapshots are re-captured only when the resolved target identity changes (SourceToMatControlTarget.GetCaptureIdentity), not on every initialize or capability edit.

Per-kind capability edits pull into MultiSourceToMatHelper.PerKindSettings so Initialize Push stays consistent. Heavy capability edits (paths, texture, camera device/resolution/facing) call InitializeAsync when the helper is not yet initialized. Helper-kind dropdown order follows ConfiguredHelperKindsFirst; unconfigured kinds are listed after configured ones with a (Not configured) suffix when that option is enabled.

◆ RebuildCapabilityUi()

void OpenCVForUnity.UnityIntegration.Helper.UI.SourceToMatControlPanel.RebuildCapabilityUi ( )

Rebuilds capability section visibility and dropdown options from the active helper / MatSource. For multi targets, section visibility follows SourceToMatControlTarget.RequestedHelperKind so the panel updates even when initialization fails.

Ensures inspector-default snapshots are available, then rebuilds each visible dropdown with a leading Default: row (when applicable) followed by Presets and runtime-supported values.
