Detailed Description

Unity WebCam device enumeration capabilities for camera IMatSource implementations.

Facing selection is provided separately by ICameraFacingControllable. Pose matrices are provided separately by IUnityCameraPoseProvider. Engine-agnostic device listing remains available via ICameraMatSource.SupportedDevices.
