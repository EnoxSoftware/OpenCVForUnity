Detailed Description

Factory for OpenCV DNN graphs, analogous to Dnn for OpenCVDnnInferenceNet.

ReadNet(string) and ReadNet(string, int) / ReadNet(string, OpenCVDnnInferenceEngineKind) load immediately via Dnn.readNet(string) / Dnn.readNet(string, string, string, int) and return a wrapped OpenCVDnnInferenceNet. The default engine is OpenCV ENGINE_AUTO: OpenCV tries the new DNN engine first and falls back to classic. The new engine does not support non-CPU backends. Use ENGINE_CLASSIC for CUDA, OpenCL, or other non-CPU backends, and when the new engine produces incorrect results (including on CPU). Apply IDnnInferenceNet.SetPreferableBackend and IDnnInferenceNet.SetPreferableTarget on the returned net before inference.
