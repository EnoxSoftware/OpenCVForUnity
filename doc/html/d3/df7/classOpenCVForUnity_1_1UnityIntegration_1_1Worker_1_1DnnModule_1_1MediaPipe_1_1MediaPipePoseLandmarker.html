Creates a pose landmarker worker backed by a pose detector model and a pose landmark model.

Parameters
poseDetectorModelFilepathFile path to the pose detection model. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, pass the full path to a serialized model that Unity.InferenceEngine.ModelLoader.Load(string) can load (e.g. .sentis); the caller may rewrite the path from ONNX.
poseLandmarksModelFilepathFile path to the pose landmark model. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, as for the detector, pass the full path to the Inference Engine serialized model.
runningModeTask running mode.
numPosesMaximum number of poses to return.
minPoseDetectionConfidenceMinimum confidence for pose detections.
minPosePresenceConfidenceMinimum presence confidence for landmark results.
minTrackingConfidenceMinimum tracking confidence to reuse the previous-frame rectangle.
outputSegmentationMasksWhen true, enables per-pose segmentation mask output.
dnnBackendInference backend: an OpenCV Dnn DNN_BACKEND_* constant, or MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS is selected, Sentis availability is validated by MultiBackendNet.SetPreferableBackend.
dnnTargetPreferred DNN target: an OpenCV Dnn DNN_TARGET_* constant, or when dnnBackend is MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, a Sentis runtime backend target id (e.g. from SentisInferenceUtils.ToTargetId).
