Detailed Description

Packed result for one detected hand, without an explicit bounding box. The memory layout matches one row produced by PackResultsToMats. NormLandmarks corresponds to the MediaPipe Task API hand_landmarks output represented as 21 <see cref="OpenCVForUnity.Extensions.Vec3f"/> values. WorldLandmarks corresponds to the MediaPipe Task API hand_world_landmarks output.
