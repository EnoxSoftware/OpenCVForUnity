Detailed Description

Shared initialization timeout budget for Grabbers.IFrameGrabber.OpenAsync and first-frame wait. Time spent inside RunOutsideTimeoutAsync does not consume the budget (for example long-running host prompts such as OS permission dialogs). A timeout of zero or less means unlimited.

async Task OpenCVForUnity.Extensions.SourceToMat.InitTimeoutBudget.RunOutsideTimeoutAsync ( Func< CancellationToken, Task > action,
CancellationToken cancellationToken )

Runs action without consuming the timeout budget. User cancellation is still honored via cancellationToken . Nested calls are not supported.

Do not use ConfigureAwait(false) on the inner await. Callers that depend on SynchronizationContext marshaling must resume on the same context after action completes (including after long-running host work such as OS permission prompts). Deadline checks remain IsExpired (the stopwatch is paused); Token is not canceled by elapsed time.

Parameters
actionThe asynchronous work to run outside the timeout budget.
cancellationTokenCancellation token for the outside work (typically the user token).
Returns
A task that completes when action completes.
