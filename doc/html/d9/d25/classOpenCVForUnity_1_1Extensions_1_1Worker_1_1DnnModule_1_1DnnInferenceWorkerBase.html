Detailed Description

Base class for ProcessingWorkerBase derivatives that record DNN runtime options (DnnBackend / DnnTarget / DnnEngine).

Initializes backend, target, and engine values exposed by DnnBackend, DnnTarget, and DnnEngine.

Parameters
dnnBackendInference backend discriminator.
dnnTargetInference target discriminator.
dnnEngineOpenCV ENGINE_* constant used when loading the model (default: ENGINE_AUTO). With ENGINE_AUTO, OpenCV tries the new DNN engine first and falls back to classic. The new engine does not support non-CPU backends. Use ENGINE_CLASSIC for CUDA, OpenCL, or other non-CPU backends, and when the new engine produces incorrect results (including on CPU).
