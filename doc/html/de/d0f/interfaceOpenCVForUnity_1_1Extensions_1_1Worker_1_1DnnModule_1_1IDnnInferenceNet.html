Detailed Description

Contract for a synchronous DNN inference net (OpenCV Net equivalent) used by DNN-based workers.

Implementations include OpenCVDnnInferenceNet (OpenCV Net). Typical construction: OpenCVDnnInferenceDnn.ReadNet(string), then SetPreferableBackend and SetPreferableTarget before SetInput / Forward.

Backend and target ids passed to SetPreferableBackend / SetPreferableTarget are defined by the implementation (OpenCV uses DNN_BACKEND_* / DNN_TARGET_*). Asynchronous inference APIs belong on separate capability interfaces (IDnnAsyncInferenceNet / IDnnAsyncNamedOutputInferenceNet), not this contract.

void OpenCVForUnity.Extensions.Worker.DnnModule.IDnnInferenceNet.Forward ( List< Mat > outputBlobs,
List< string > outBlobNames )

Runs a forward pass and fills outputBlobs using the given output layer names.

OpenCV-based implementations (e.g. OpenCVDnnInferenceNet) own the Mat instances produced by the internal forward call: they dispose outputs from the previous call on the next Forward and in IDisposable.Dispose. Callers must not dispose those Mats.

Parameters

outBlobNamesOutput layer names in the same count and OpenCVForUnity.Extensions.Worker.Utils.DnnInferenceNetUnconnectedOutLayersNames.LAYER_NAME_COMPARER order as GetUnconnectedOutLayersNames.

Implemented in OpenCVForUnity.Extensions.Worker.DnnModule.OpenCVDnnInferenceNet, OpenCVForUnity.UnityIntegration.Worker.DnnModule.MultiBackendNet, and OpenCVForUnity.UnityIntegration.Worker.DnnModule.SentisInferenceNet.

◆ GetUnconnectedOutLayersNames()

List< string > OpenCVForUnity.Extensions.Worker.DnnModule.IDnnInferenceNet.GetUnconnectedOutLayersNames ( )

Returns the model's unconnected output layer (tensor) names sorted with OpenCVForUnity.Extensions.Worker.Utils.DnnInferenceNetUnconnectedOutLayersNames.LAYER_NAME_COMPARER.

Implementations must not return engine-specific ordering. Use OpenCVForUnity.Extensions.Worker.Utils.DnnInferenceNetUnconnectedOutLayersNames.CreateSortedCopy when caching raw names from the underlying inference engine.

Returns
A new list of output layer names in OpenCVForUnity.Extensions.Worker.Utils.DnnInferenceNetUnconnectedOutLayersNames.LAYER_NAME_COMPARER order.

Implemented in OpenCVForUnity.Extensions.Worker.DnnModule.OpenCVDnnInferenceNet, OpenCVForUnity.UnityIntegration.Worker.DnnModule.MultiBackendNet, and OpenCVForUnity.UnityIntegration.Worker.DnnModule.SentisInferenceNet.
