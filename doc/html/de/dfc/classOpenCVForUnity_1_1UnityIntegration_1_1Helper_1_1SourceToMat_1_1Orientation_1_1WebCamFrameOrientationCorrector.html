Detailed Description

Applies WebCam-specific orientation correction after IFrameGrabber.TryGrab.

Applies flip and rotation for WebCam grabber frames after IFrameGrabber.TryGrab (FlipAndRotateMat / FlipMat / NeedsRotatedFrameMat). When a rotated buffer is supplied, in-place flips on the source are undone after the rotate/resize so the source Mat can remain a raw grabber frame. User-specified FlipVertical / FlipHorizontal / Rotate90Degree are not applied here; those remain on IMatTransformable / MatSourceBase. Display orientation prefers NotifyDisplayOrientationChanged; when never notified, Apply falls back to Screen.orientation. Sync and AsyncGPU WebCam grabbers share one corrector instance; AsyncGPU uses the same pixel-order offsets as the sync grabber path.
