Detailed Description

Per-kind inspector setting cache used by MultiSourceToMatHelper when swapping the active child helper (Pull before destroy, Push after add).

Field names match MultiSourceHelperKind values. Fields mirror each concrete helper's *SourceInspectorSettings types. Custom helpers use a component reference on MultiSourceToMatHelper and have no cache entry here.
