Detailed Description

AsyncGPUReadback-based IFrameGrabber for Unity Texture sources. Returns a new frame from TryGrab only when a capture request has completed (or when delivering the first frame captured during OpenAsync). The Open body runs inside SourceToMatSynchronizationContextScope.

Texture frame pipeline (hot path):

  1. RequestCapture calls BeginCaptureFromRequest to issue a GPU readback for the current source texture.
  2. OnAsyncReadbackComplete stores the latest completed readback in _asyncGpuReadbackRequest and marks it ready to commit.
  3. TryGrab calls TryCommitPendingCapture at most once per tick to copy the latest completed frame into _frameMat and return it.

Parallel readbacks are allowed across capture requests. Only the latest completed capture is committed, at most once per TryGrab call. _readbackGeneration invalidates in-flight readbacks on pause, stop, and close.

During OpenAsync, an uncreated RenderTexture source is polled until RenderTexture.IsCreated before async-readback support is evaluated. Set RequestedUseAsyncGPUReadback before open to request async readback; read EffectiveUseAsyncGPUReadback after open to observe the applied mode. Sync fallback is chosen when async readback is not requested, unsupported on the platform, or unsupported for the source texture format.
