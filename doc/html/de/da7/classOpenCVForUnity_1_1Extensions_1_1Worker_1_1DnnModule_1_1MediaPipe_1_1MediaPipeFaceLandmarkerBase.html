◆ Detect()

Mat[] OpenCVForUnity.Extensions.Worker.DnnModule.MediaPipe.MediaPipeFaceLandmarkerBase< TNet >.Detect ( Mat image,
bool useCopyOutput = false )

High-level inference API equivalent to the synchronous detect entry points of MediaPipe FaceLandmarker. Returns one to three packed output matrices depending on which optional outputs are enabled.

Parameters
imageInput image in BGR 3-channel format. Corresponds to the input image consumed by the MediaPipe face landmarker graph.
useCopyOutputIf true, returns a copied output matrix. If false, returns a view backed by the worker's reusable output buffer.
Returns
Packed result matrices with length 1 or 3. The length is 3 when either outputFaceBlendshapes or outputFacialTransformationMatrixes is enabled, otherwise 1. Element [0] is the packed face result matrix with one row per detected face and FaceLandmarkerEstimationData.ELEMENT_COUNT columns per row. Element [0] is returned as CV_32FC1, and each row matches the memory layout of FaceLandmarkerEstimationData: columns [0 .. 1433] store 478 normalized face landmarks as xyz triplets. When the array length is 3, element [1] contains packed blendshape coefficients or an empty Mat when disabled, with each row returned as CV_32FC1, containing 52 coefficients in category order, and matching the memory layout of FaceBlendshapeEstimationData. Element [2] contains packed row-major 4x4 facial transformation matrices or an empty Mat when disabled, with each row returned as CV_32FC1, containing 16 float values, and matching the memory layout of FacialTransformationMatrixEstimationData.

◆ ResetTrackingState()

virtual void OpenCVForUnity.Extensions.Worker.DnnModule.MediaPipe.MediaPipeFaceLandmarkerBase< TNet >.ResetTrackingState ( )
virtual

Clears inter-frame tracking state held between frames.

Resets _prevFaceRectsFromLandmarks (previous-frame face ROI loopback) and landmark smoothing filters. In IMAGE mode, ProcessImageData already clears face ROI loopback on every call, so this method is effectively a smoothing reset only when num_faces == 1 and VIDEO-mode smoothing is enabled; it is still safe to call when the input source, resolution, or layout changes. In VIDEO mode, call this when prior tracking must not influence the next inference.
