Returns whether ProduceOutputMat can read the source without mutating it or returning that same instance.

Returns true when color conversion or a 90-degree rotation will produce a separate result, and neither flip is requested. Flip is applied in place, so any flip request returns false. When this method returns true, ProduceOutputMat does not write to the source mat and does not return that instance. The caller keeps ownership of the source and disposes only the returned mat. When this method returns false, the result may be the source mat after an in-place flip. Pass an owned copy if the original pixels must be preserved.

flipHorizontalWhether a horizontal flip is requested.
Returns
true when the source can be read without copy because conversion or rotation allocates a separate result and no flip is requested; otherwise false.

Produces an output mat from a grabber-sized source: color conversion, optional 90-degree clockwise rotation, and flip.

Does not take ownership of sourceMat . When the returned instance is not sourceMat , the caller still owns sourceMat . When the returned instance is sourceMat , dispose only the result. Flip may mutate sourceMat in place when sourceColorFormat already matches outputColorFormat . The caller owns the returned mat and must dispose it. When CanReadSourceWithoutCopy is true for the same color formats, rotation, and flip arguments, this method does not mutate sourceMat and does not return that instance. When CanReadSourceWithoutCopy is false, the result may be sourceMat after an in-place flip. Pass an owned copy if the original pixels must be preserved. colorConversionScratch is an optional color-conversion destination used only when converting color and rotating. It is never returned. When rotation produces a separate mat, this method does not dispose the scratch so the caller can reuse it. When null, conversion allocates a one-shot mat. Size or type mismatch is reallocated with Mat.create(int, int, int).

Parameters

rotate90DegreeWhether to rotate 90 degrees clockwise after flip.
