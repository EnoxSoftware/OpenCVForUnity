Detailed Description

Resolves Unity-side file paths for SourceToMat helpers. Accepts a path relative to the StreamingAssets folder or an absolute URI/path string, and returns a host-resolved readable path for Extensions grabbers and options.

Use ResolvePath / ResolvePathAsync for OpenCV file I/O consumers (for example VideoCapture and image codecs). Use ResolveVideoPlayerPath / ResolveVideoPlayerPathAsync for Unity VideoPlayer URL loading (for example on WebGL, where a StreamingAssets HTTP URL is required).

static string OpenCVForUnity.UnityIntegration.Helper.SourceToMat.SourceToMatUnityPath.ResolveVideoPlayerPath ( string requestedPath)
static

Synchronously resolves requestedPath to a URL or path suitable for Unity VideoPlayer.

Parameters
requestedPathA path relative to the StreamingAssets folder or an absolute path/URI.
Returns
A VideoPlayer-loadable URL or path, or string.Empty when requestedPath is empty. Relative paths are combined with Application.streamingAssetsPath without copying via OpenCVForUnityEnv.

This resolver targets Unity VideoPlayer (VideoPlayer.url), not OpenCV file I/O. Use ResolvePath for VideoCapture and image codecs.

Absolute URIs (http://, https://, file://, and other schemes accepted by System.Uri) are returned unchanged. Relative paths are prefixed with Application.streamingAssetsPath.

On WebGL, Application.streamingAssetsPath is typically an HTTP(S) URL rather than a local directory path. The returned value is suitable for VideoPlayer.url in that environment. Do not substitute ResolvePath here; OpenCV copy/download resolution is not used.
