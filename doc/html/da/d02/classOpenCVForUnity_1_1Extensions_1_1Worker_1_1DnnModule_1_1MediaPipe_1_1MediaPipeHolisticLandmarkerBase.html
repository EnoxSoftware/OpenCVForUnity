Detailed Description

Shared MediaPipe HolisticLandmarker algorithm implementation for any IDnnInferenceNet backend. Reproduces the holistic landmarking graph logic of MediaPipe HolisticLandmarker on top of the OpenCV Net DNN module.

◆ Detect()

Mat[] OpenCVForUnity.Extensions.Worker.DnnModule.MediaPipe.MediaPipeHolisticLandmarkerBase< TNet >.Detect ( Mat image,
bool useCopyOutput = false )

High-level inference API equivalent to the synchronous detect entry points of MediaPipe HolisticLandmarker. Returns a packed output array whose slots correspond to the public holistic result streams.

Parameters
imageInput image in BGR 3-channel format. Corresponds to the input image consumed by the MediaPipe holistic landmarker graph.
useCopyOutputIf true, returns a copied output matrix. If false, returns a view backed by the worker's reusable output buffer.
Returns
Fixed-length array of HOLISTIC_PACKED_OUTPUT_SLOT_COUNT entries following the public holistic contract. Filled slots are either one packed CV_32FC1 row or a 2D Mat for segmentation. Slot 0: MediaPipePoseLandmarkerBase<OpenCVForUnity.Extensions.Worker.DnnModule.IDnnInferenceNet>.PoseLandmarkerEstimationData. Slots 1 and 2: left/right MediaPipeHandLandmarkerBase<OpenCVForUnity.Extensions.Worker.DnnModule.IDnnInferenceNet>.HandLandmarkerEstimationData. Slot 3: MediaPipeFaceLandmarkerBase<OpenCVForUnity.Extensions.Worker.DnnModule.IDnnInferenceNet>.FaceLandmarkerEstimationData. Slot 4: full-resolution pose segmentation mask. Slot 5: one row of 52 coefficients equivalent to MediaPipeFaceLandmarkerBase<OpenCVForUnity.Extensions.Worker.DnnModule.IDnnInferenceNet>.FaceBlendshapeEstimationData. Disabled slots are empty Mat instances.

async Task< Mat[]> OpenCVForUnity.Extensions.Worker.DnnModule.MediaPipe.MediaPipeHolisticLandmarkerBase< TNet >.DetectAsync ( Mat image,

Asynchronous inference API equivalent to the async detect entry points of MediaPipe HolisticLandmarker. The effective behavior still depends on the configured runningMode.

Parameters
imageInput image in BGR 3-channel format. Corresponds to the input image consumed by the MediaPipe holistic landmarker graph.
cancellationTokenCancellation token for the C# async operation.
Returns
Same slot contract as Detect(Mat, bool); returns only copied Mat instances.

For the OpenCV Dnn module, inference is scheduled on a background thread when thread-pool scheduling is available. Web builds cannot use thread pools; only then does the OpenCV Dnn path run synchronously on the caller thread.

Resets pose ROI loopback, hand/face landmark loopback, segmentation-smoothing loopback, and landmark smoothing filters. Safe to call in any running mode when the input source, resolution, or layout changes and prior tracking must not influence the next inference.
