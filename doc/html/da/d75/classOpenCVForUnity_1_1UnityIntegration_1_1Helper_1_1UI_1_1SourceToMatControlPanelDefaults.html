Detailed Description

Inspector-default capability snapshots used by SourceToMatControlPanel dropdown rows labeled Default:.

CaptureFrom is invoked when the panel binds a target or when SourceToMatControlTarget.GetCaptureIdentity changes. It is not refreshed on SourceToMatHelperBase.OnInitialized or routine capability edits.

Single helper: reads the active helper control contracts at capture time. Multi built-in kinds: reads MultiSourceToMatHelper.PerKindSettings per MultiSourceHelperKind so each kind keeps its own default snapshot. Multi Custom: reads MultiSourceToMatHelper.CustomHelperComponent because Custom is excluded from per-kind Pull/Push caches.

Default rows are always prepended when a capability applies, including empty paths and null textures. Presets may duplicate the same underlying value; both labels remain in the dropdown. Empty default camera device names are omitted from the dropdown because Auto already represents them.
