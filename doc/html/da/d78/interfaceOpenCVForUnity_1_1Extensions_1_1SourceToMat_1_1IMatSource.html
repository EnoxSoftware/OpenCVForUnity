Detailed Description

Base contract for converting a media source into an owned, reusable FrameMat buffer.

Single-threaded hosts: Product teardown must call IAsyncDisposable.DisposeAsync; do not use IDisposable.Dispose on browser/WebAssembly targets. IDisposable.Dispose remains for Editor and other multi-threaded hosts. There is no safe way to wait for incomplete async work on a single-threaded host from IDisposable.Dispose.

◆ FrameMat

Mat OpenCVForUnity.Extensions.SourceToMat.IMatSource.FrameMat
get

Gets the owned reusable output buffer. Do not dispose this Mat.

The returned Mat is reused every frame. Disposing it is unsupported. Implementations may log a warning and recreate the buffer on the next update when it was disposed accidentally. While MatSourceState.Initializing, uninitialized, or released, returns null.
