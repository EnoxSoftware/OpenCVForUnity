Detailed Description

Shared ordering contract for DnnModule.IDnnInferenceNet.GetUnconnectedOutLayersNames and DnnModule.IDnnInferenceNet.Forward(System.Collections.Generic.List<CoreModule.Mat>, System.Collections.Generic.List<string>).

Underlying inference engines may return unconnected output layer names in different orders. Implementations of DnnModule.IDnnInferenceNet must normalize names with CreateSortedCopy before caching or returning them so detectors can rely on a stable index mapping across backends and OpenCV versions.
