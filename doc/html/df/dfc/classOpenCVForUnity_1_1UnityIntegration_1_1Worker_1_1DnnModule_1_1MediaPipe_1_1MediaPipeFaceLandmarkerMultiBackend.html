Detailed Description

MediaPipe FaceLandmarker with Unity multi-backend inference (OpenCV DNN and Sentis).

This is the primary Unity entry point for MediaPipe FaceLandmarker. Inference runs through MultiBackendNet, which supports OpenCV DNN and Unity Sentis backends. For OpenCV-DNN-only usage, use OpenCVForUnity.Extensions.Worker.DnnModule.MediaPipe.MediaPipeFaceLandmarker instead.

Parameters
faceDetectorModelFilepathFile path to the face detector model. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, pass the full path to a serialized model that Unity.InferenceEngine.ModelLoader.Load(string) can load (e.g. .sentis).
faceLandmarksModelFilepathFile path to the face landmarks model. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, pass the full path to the Inference Engine serialized model.
runningModeTask running mode.
numFacesMaximum number of faces to return.
minFaceDetectionConfidenceMinimum confidence for face detections.
minFacePresenceConfidenceMinimum presence confidence for landmark results.
minTrackingConfidenceMinimum tracking confidence to reuse the previous-frame rectangle.
outputFaceBlendshapesWhen true, enables blendshape output.
faceBlendshapesModelFilepathFile path to the face blendshapes model when blendshapes are enabled.
outputFacialTransformationMatrixesWhen true, enables facial transformation matrix output.
faceGeometryPipelineMetadataFilepathPath to geometry pipeline metadata pbtxt when facial pose output is enabled.
dnnBackendInference backend: an OpenCV Dnn DNN_BACKEND_* constant, or MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS. When MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS is selected, Sentis availability is validated by MultiBackendNet.SetPreferableBackend.
dnnTargetPreferred DNN target: an OpenCV Dnn DNN_TARGET_* constant, or when dnnBackend is MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS, a Sentis runtime backend target id (e.g. from SentisInferenceUtils.ToTargetId).
engineOpenCV Dnn ENGINE_* constant used when loading the OpenCV path (default: ENGINE_AUTO). Ignored when dnnBackend is MultiBackendDnn.DNN_BACKEND_UNITY_SENTIS. With ENGINE_AUTO, OpenCV tries the new DNN engine first and falls back to classic. The new engine does not support non-CPU backends. Use ENGINE_CLASSIC for CUDA, OpenCL, or other non-CPU backends, and when the new engine produces incorrect results (including on CPU).
