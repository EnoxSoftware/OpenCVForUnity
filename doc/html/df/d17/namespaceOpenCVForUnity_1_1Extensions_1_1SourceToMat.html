class  MatSourceBase
 Concrete IMatSource that drives an injected IFrameGrabber and an optional IFrameOrientationCorrector. Owns _frameMat, a lazy _rotatedBuffer used only for user 90-degree rotation, and a lazy orientation scratch used only when orientation correction needs a swapped-size buffer and the output color format differs from the grabber. When user rotation is off, _rotatedBuffer is released. When the orientation scratch is not required, it is released. Grabber frames from IFrameGrabber.TryGrab are treated as read-only. Implements IMatTransformable only; IMatUpdateFPSControllable is implemented by derived sources such as ImageFileMatSource and by integration-layer mat sources that throttle texture readback. Also implements IMatSourceEvents, IMatSourceTickable, IMatSourceReinitializable, and IMatSourceDerivedFrames for host event subscription, per-tick acquisition, source-swap re-initialization, and derived frame registration. ◆ MatSourceState

enum OpenCVForUnity.Extensions.SourceToMat.MatSourceState

Lifecycle state of an IMatSource implementation.

Enumerator
Uninitialized 

Idle state after the underlying grabber has been closed. Initialization in progress is represented by Initializing. Re-initialization is allowed from this state.

Initializing 

Initialize pipeline is in progress (including grabber open).

Ready 

Initialized and ready. Frame acquisition is stopped.

Playing 

Frame acquisition is active.

Paused 

Frame acquisition is paused.

Destroyed 

Disposed. No further operations are allowed.

enum OpenCVForUnity.Extensions.SourceToMat.SourceToMatErrorCode : int

Error codes reported by SourceToMat sources through the error event. Expected runtime failures use these codes instead of SourceToMatException.

Enumerator
UNKNOWN 

Unclassified failure. Use when no more specific code applies; details belong in the event message.

CAMERA_DEVICE_NOT_EXIST 

No camera devices are available.

CAMERA_PERMISSION_DENIED 

Camera access was denied by the platform (permission not granted).

CAMERA_DEVICE_NOT_FOUND 

The requested camera device name or index was not found in the device list.

CAMERA_CANT_OPEN 

A camera device exists but could not be opened (for example, the host capture API or OpenCV VideoCapture.open failed).

CAMERA_RESOLUTION_UNSUPPORTED 

The requested width, height, or frame rate is not supported by the selected camera device.

CAMERA_START_FAILED 

Camera capture was created but did not start delivering frames (other than init timeout).

VIDEO_FILE_NOT_EXIST 

The requested video file path does not resolve to an existing file.

VIDEO_FILE_CANT_OPEN 

The video file exists but could not be opened (for example, OpenCV VideoCapture.isOpened() is false).

FILE_PATH_NOT_RESOLVED 

The file path string is set but the full path could not be resolved by the host environment.

IMAGE_FILE_NOT_EXIST 

The requested image file path does not resolve to an existing file.

IMAGE_FILE_CANT_OPEN 

The image file exists but could not be read (for example, Imgcodecs.imread failed).

IMAGE_FILE_INVALID 

The image file exists but decoded to an empty or invalid matrix (corrupt or unsupported image data).

HOST_VIDEO_ERROR 

The host video player reported an error during prepare or playback.

HOST_VIDEO_PREPARE_FAILED 

Host video prepare did not complete successfully before initialization finished or timed out.

HOST_VIDEO_UNAVAILABLE 

A host video player required by the grabber could not be found or created.

SOURCE_TEXTURE_IS_NULL 

The source texture reference is null at initialization.

SOURCE_TEXTURE_FORMAT_UNSUPPORTED 

The source texture pixel format is not supported for GPU readback or conversion.

GPU_READBACK_UNSUPPORTED 

GPU readback is not supported on the current platform or device.

GPU_READBACK_FAILED 

A GPU readback operation failed during initialization or frame acquisition.

RENDER_TARGET_FORMAT_UNSUPPORTED 

The render target graphics format is not supported for the chosen readback path.

RENDER_TARGET_CREATE_FAILED 

A render target required for frame capture could not be created.

TIMEOUT 

Initialization did not complete within InitTimeoutMs.

OPERATION_CANCELED 

An async operation was canceled via System.Threading.CancellationToken.

FRAME_GRAB_FAILED 

Frame acquisition failed persistently while the source is playing. A single IFrameGrabber.TryGrab returning false (no new frame) is not this error.

SOURCE_LOST 

The capture source was lost during playback (for example, camera unplugged or handle invalidated).
