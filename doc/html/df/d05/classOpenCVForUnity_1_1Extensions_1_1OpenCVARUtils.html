OpenCV AR utilities (engine-independent: drawing, frustum, projection, pose, Mat4d TRS).

OpenCV AR utilities — Unity Integration partial (Quaternion/Vector3 sugar, Unity projection, TRS / Transform / handedness).

double far = 2000::0 )
static

Builds a 4×4 projection matrix from OpenCV-style camera intrinsics.

Convention (fixed for this core API): OpenCV image origin is top-left (Y down); the returned matrix uses a Y-up principal-point mapping (m12 = -1 + 2*cy/height), matching a common AR camera projection matrix layout in row-major Mat4d elements. No engine runtime is required.

Parameters
fxFocal length along the X axis (pixels).
fyFocal length along the Y axis (pixels).
cxPrincipal point X coordinate (pixels).
cyPrincipal point Y coordinate (pixels).
widthImage width (pixels).
heightImage height (pixels).
nearNear clipping plane distance.
farFar clipping plane distance.
Returns
Row-major 4×4 projection matrix.
